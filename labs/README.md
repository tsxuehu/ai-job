# 实验目录

实验用来验证一个具体机制或故障，不追求完整产品。每个实验都应在独立环境中复现，并把结论接入 P0、P1 或 P2 项目。

## 推荐实验

| 实验 | 阶段 | 验证能力 | 项目映射 |
| --- | --- | --- | --- |
| [请求链路观测](01-请求链路观测.md) | L0—L1 | DNS、TCP、HTTP、日志和 Trace | P0 |
| [数据库与缓存一致性](02-数据库与缓存一致性.md) | L1—L2 | 事务、缓存策略、并发和补偿 | P1 |
| [超时重试与故障注入](03-超时重试与故障注入.md) | L2 | 超时预算、重试放大、熔断和降级 | P1/P2 |
| [RAG 评测](04-RAG评测.md) | L2 | 数据集、检索指标、引用和回归 | P2 |

## 完成标准

- 明确问题、假设和成功条件。
- 记录环境、版本、数据和可重复步骤。
- 保留指标、日志、Trace 或测试结果。
- 解释结果与原理是否一致，以及可能的干扰因素。
- 写出项目中的使用方式和不能直接外推的限制。

使用 [实验报告模板](../templates/实验报告模板.md) 记录结果。
