# 实验：超时、重试与故障注入

## 目标

理解调用链上的超时预算、重试放大和级联故障，验证限流、熔断、降级和隔离的效果。

## 任务

1. 构造客户端 → 服务 A → 服务 B → 数据库的调用链。
2. 为不同层设置连接、读取和总请求超时。
3. 注入延迟、错误、连接耗尽和间歇性失败。
4. 比较无重试、固定重试、指数退避加抖动的请求量和成功率。
5. 加入重试预算、熔断或并发隔离，记录系统恢复过程。
6. 验证非幂等操作在重试下是否产生重复副作用。

## 必须回答

- 下游超时为什么必须小于上游总预算？
- 哪些错误值得重试，哪些不应该重试？
- 重试如何放大流量和延长尾延迟？
- 降级返回什么，由业务而不是框架决定的部分有哪些？

## 验收证据

- 故障前后的成功率、吞吐和 P95/P99 延迟。
- 调用次数放大比例和恢复时间。
- 一份包含止损、恢复和防复发措施的实验复盘。
