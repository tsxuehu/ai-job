# 技能掌握检查表

评分：L0 不了解；L1 能解释；L2 能实现并交付；L3 有真实生产责任并能优化；L4 能解决复杂问题并指导他人。

每个勾选项都应附一个证据链接。没有代码、实验、项目、指标或真实经历支持时，最高只能标为 L1。完整定义参见 [能力模型](../docs/00-开始这里/能力模型.md)。

## 主语言

- [ ] 不依赖 AI 完成中等难度编码并覆盖测试。
- [ ] 解释运行时、并发、内存和资源释放。
- [ ] 实现超时、取消、限流、重试和优雅停机。
- [ ] 使用该语言工具定位 CPU、内存、阻塞和竞争。

## 后端基础

- [ ] 算法、操作系统、网络不存在明显盲区。
- [ ] 能设计表结构、索引、事务并分析慢 SQL。
- [ ] 能处理缓存一致性、热点和故障降级。
- [ ] 能处理消息重复、丢失、乱序、积压和重放。
- [ ] 能设计幂等、最终一致、高可用和容灾。

## 生产工程

- [ ] 有测试、容器、CI/CD、灰度和回滚实践。
- [ ] 能定义日志、指标、追踪、SLI/SLO 和告警。
- [ ] 能结构化排查 P99、CPU、内存与依赖故障。
- [ ] 能进行容量估算、压测和成本分析。

## AI 应用

- [ ] 能可靠接入模型 API、流式和结构化输出。
- [ ] 能设计含权限、引用、更新和评测的 RAG。
- [ ] 能设计受控、可恢复、可审计的 Agent 工具链。
- [ ] 有 Golden Dataset、回归评测和线上反馈闭环。
- [ ] 能防提示注入、数据泄漏和工具越权。
- [ ] 能量化质量、首 token 延迟和单位任务成本。
