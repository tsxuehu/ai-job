# 一、需要具备的技能

目标是能够独立交付生产系统，并把 AI 能力可靠接入业务。学习时采用“一门主语言、一门辅助语言、其余能够阅读”的策略。

开始学习前先完成 [能力自评](../00-开始这里/能力模型.md) 和 [路线选择](../00-开始这里/路线选择.md)。本目录是能力地图，不要求从第一篇按顺序读到最后一篇。

## 按阶段使用

| 阶段 | 学习重点 | 实践出口 |
| --- | --- | --- |
| L0 | 主语言、算法、操作系统、Linux、网络 | 小型程序和基础实验 |
| L1 | API、数据库、鉴权、测试、容器 | P0 基础后端服务 |
| L2 | 缓存、消息、分布式、观测、发布、排障 | P1 生产级业务系统 |
| L2 AI 专项 | 模型 API、RAG、Agent、Evals、安全、成本 | P2 企业知识库与业务 Agent |
| L3—L4 | 真实系统责任、架构演进、组织影响力 | 生产指标、事故复盘和跨团队方案 |

## 学习优先级

- 必修：主语言、算法、操作系统、网络、数据库、缓存、消息队列、分布式、测试和排障。
- 进阶：容器、发布、可观测性、安全、系统设计和 AI 辅助开发。
- AI 岗位必修：模型 API、RAG、Agent、Evals、AI 安全、延迟和成本。
- 岗位专项：Kubernetes 深入、平台工程、GPU、CUDA、推理优化等内容。

## 学习要求

每个主题至少经过“解释原理 → 完成实验 → 接入项目 → 模拟追问”四步。具体方法参见 [学习与验收方法](../00-开始这里/学习与验收方法.md)，新增内容使用 [学习章节模板](../../templates/学习章节模板.md)。
