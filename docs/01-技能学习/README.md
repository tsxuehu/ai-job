## 优先级

- P0：主语言、算法、操作系统、网络、数据库、缓存、消息队列、分布式、测试和排障。
- P1：容器、发布、可观测性、安全、系统设计和 AI 辅助开发。
- AI 岗位 P1：模型 API、RAG、Agent、Evals、AI 安全、延迟和成本。
- P2：Kubernetes 深入、平台工程、GPU、CUDA、推理优化等岗位专项。
