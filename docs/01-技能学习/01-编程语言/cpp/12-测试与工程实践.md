# C++：测试与工程实践

C++ 工程质量依赖编译器、静态分析、动态检测和测试共同约束，单靠单元测试覆盖不了未定义行为和并发问题。

## 测试分层

- 单元测试：值对象、算法、解析和状态转换。
- 组件测试：存储、队列、线程池和第三方库包装。
- 集成测试：文件、数据库、网络和进程边界。
- 并发测试：重复运行、随机调度、超时、取消和关闭。
- 模糊测试：解析器、协议和所有不可信输入。

除了正常路径，还要注入分配失败、部分读写、异常、超时和依赖不可用。

## 调试与检测

| 工具 | 主要用途 |
| --- | --- |
| GDB / LLDB | 断点、变量、线程、core dump、调用栈 |
| AddressSanitizer | 越界、use-after-free 等内存错误 |
| UndefinedBehaviorSanitizer | 部分未定义行为 |
| ThreadSanitizer | 数据竞争和部分同步错误 |
| clang-tidy / 静态分析 | 接口误用、生命周期和代码缺陷 |
| profiler / 火焰图 | CPU、锁、分配和系统调用热点 |

不同 sanitizer 通常分别构建运行；工具无报告不等于程序被证明正确。

## 工程基线

- 固定语言标准、编译器和依赖，使用 target 化构建。
- CI 执行严格警告、格式、静态检查、测试和 sanitizer 任务。
- Debug 保留符号和断言，Release 使用真实优化配置。
- 保存构建版本、符号、core dump 和发布清单，支持线上定位。
- 为内存、线程、文件描述符、连接和队列设置上限。
- 生产服务支持超时、取消、过载拒绝和优雅停机。

## 综合项目

实现一个有界并发任务服务，包含配置解析、任务提交、超时、取消、拒绝、优雅停机、指标和故障注入。分别用 ASan、UBSan 和 TSan 验证，并提交一份基于 profiler 的性能报告。

## 最终验收

- [ ] 能独立构建、测试、调试和部署项目。
- [ ] 能定位越界、悬垂、未定义行为、竞争和性能热点。
- [ ] 能解释对象、线程、依赖和构建产物的生命周期。
- [ ] CI 与生产诊断信息足以复现和定位真实故障。
