# C++：变量、数据与类型

C++ 的类型不仅描述数据形状，还经常表达对象是否拥有资源、能否修改以及生命周期关系。

## 基础类型与业务类型

- 布尔：`bool`。
- 整数：`char`、`short`、`int`、`long` 等；协议和存储格式使用 `<cstdint>` 的固定宽度类型。
- 浮点：`float`、`double`；精确金额使用整数最小单位或十进制库。
- 文本：`std::string` 拥有数据，`std::string_view` 只是只读视图。
- 可选值：`std::optional<T>`；不要用 `-1` 或空字符串暗示“没有值”。

```cpp
struct UserId { std::uint64_t value; };
struct OrderId { std::uint64_t value; };

const UserId user_id{42};
std::optional<std::string> nickname;
```

即使底层都是整数，独立业务类型也能阻止把用户编号误传为订单编号。

## 值、引用与指针

| 形式 | 主要语义 | 常见用途 |
| --- | --- | --- |
| `T` | 独立值，可能复制或移动 | 小对象、值语义、所有权转移 |
| `T&` | 非空、非拥有、可修改 | 修改调用者对象 |
| `const T&` | 非空、非拥有、只读 | 避免复制大对象 |
| `T*` | 地址可为空，通常不拥有 | 可选观察、底层接口 |
| 智能指针 | 动态对象的所有权 | 独占或共享生命周期 |

引用、裸指针、`string_view` 和 `span` 都不会延长底层对象生命周期。

## const、推断和转换

- `const` 约束通过当前访问路径能否修改对象；区分“指向常量的指针”和“常量指针”。
- `auto` 会按规则丢掉顶层引用或 `const`，需要保留时使用 `auto&`、`const auto&`。
- 避免不受控的隐式窄化、有符号与无符号混算。
- 用 `static_cast` 等显式转换表达意图；类型转换不会自动验证业务范围。

## 复制与移动

值对象被复制后彼此独立；移动把资源转交给新对象。被移动对象仍可析构和重新赋值，但不要继续依赖它原来的业务值。资源类优先遵循 Rule of Zero，让标准类型自动生成正确的复制、移动和析构行为。

## 易错点

- 返回指向局部变量的引用、指针或视图。
- 把无符号整数减到零以下，得到很大的正数。
- 把浮点相等比较用于金额或累计计算。
- 误以为 `std::move` 会移动；它只是把表达式转换为可移动形式。

## 验收

- 能从函数签名判断值、借用和所有权转移。
- 能解释 `string` 与 `string_view`、复制与移动的生命周期差异。
- 能识别未初始化、溢出、窄化和悬垂数据风险。
