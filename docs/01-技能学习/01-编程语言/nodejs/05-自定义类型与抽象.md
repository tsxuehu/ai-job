# Node.js / TypeScript：自定义类型与抽象

TypeScript 同时提供结构类型、interface/type 和 class；设计时要分清编译期契约与 JavaScript 运行时对象模型。

## type、interface 与判别联合

- interface 定义对象形状，可 extends 并支持声明合并。
- type 可表达联合、交叉、元组、映射和条件类型。
- 判别联合适合有限状态，通常比布尔字段组合更安全。
- 结构类型意味着形状兼容即可赋值，不要求显式 implements。

```ts
interface Store {
  get(id: TaskId, signal: AbortSignal): Promise<Task | undefined>;
}
```

## class、封装与继承

class 是真实运行时构造器和原型对象。`private`/`protected` 主要由 TypeScript 检查；需要运行时私有使用 `#field`。构造器建立不变量，不要只把 DTO 包装成 getter/setter。

继承基于原型链并支持方法覆盖，但会耦合实现和子类型关系。优先组合依赖与小接口；只在稳定替换关系下继承。多态既可由 class 继承产生，也可由结构接口让无关对象满足同一契约。

## 泛型与抽象边界

```ts
function indexBy<T, K extends PropertyKey>(
  items: readonly T[],
  key: (item: T) => K,
): Map<K, T> { /* ... */ }
```

泛型适合数据结构和算法关系；复杂条件类型会增加编辑器和团队理解成本。外部依赖通过由使用方定义的小接口隔离，运行时输入通过 schema 校验。

## 验收

- 能区分 type、interface、class 和运行时对象。
- 能用私有状态、构造校验和组合维护不变量。
- 能解释结构类型、原型继承、接口多态与泛型擦除。
