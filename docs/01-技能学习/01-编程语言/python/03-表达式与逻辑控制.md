# Python：表达式与逻辑控制

Python 表达式简洁，但真值、链式比较、短路和推导式的隐含行为需要明确。

## 表达式与真值

- `and`/`or` 短路并返回操作数，不保证返回 bool。
- `None`、False、数值零和空容器是假值；“缺失”与“合法空值”要分别判断。
- `a < x <= b` 是链式比较，只计算中间表达式一次。
- `/` 是浮点除法，`//` 是向下取整除法，负数边界要测试。
- `is None` 判断缺失，字符串/数字/容器值使用 `==`。

## if、循环与推导式

```python
if not request.valid:
    return reject(request)

ready_ids = [task.id for task in tasks if task.is_ready]
```

`for` 遍历 iterable，`while` 用于条件循环；循环可带 `else`，表示没有被 break 时执行。推导式适合单层清晰转换，嵌套副作用逻辑使用普通循环。

## 模式匹配

```python
match result:
    case Success(value=value):
        return value
    case Failure(error=error):
        raise error
```

结构化模式匹配根据形状和模式绑定名称，不是其他语言 switch 的简单别名。静态检查未必保证所有运行时对象穷举，必要时保留明确兜底错误。

## 海象运算符与作用域

`:=` 可在表达式中绑定重复计算结果，适合 while 读取等局部模式；过度使用会降低可读性。推导式有自己的作用域，但其中捕获的外部可变状态仍需谨慎。

## 验收

- 能解释真值、短路返回值、链式比较和除法语义。
- 能选择 if、for、while、推导式和 match。
- 能区分缺失值、空值和错误状态，并覆盖边界分支。
