# Python：自定义类型与抽象

Python 的 class 是运行时对象，支持继承、多态和动态修改；类型提示又提供 Protocol、泛型等静态抽象，两层需要同时理解。

## dataclass、class 与 Enum

- dataclass 适合字段明确的数据对象，可生成初始化、比较和 repr。
- 普通 class 适合维护身份、资源和不变量的对象。
- Enum 表达有限常量，避免字符串散落。
- `__slots__` 可限制实例属性并影响内存，但不是安全封装机制。

```python
@dataclass(frozen=True, slots=True)
class TaskId:
    value: int

    def __post_init__(self) -> None:
        if self.value <= 0:
            raise ValueError("value must be positive")
```

前导下划线表达内部成员，双下划线会名称改写但不是权限控制。封装依赖清晰 API、property 和不变量，不是 getter/setter 模板。

## 继承、组合与 MRO

Python 支持多继承，方法解析顺序遵循 MRO；`super()` 沿 MRO 协作调用，不只是“父类方法”。Mixin 应小而无状态。业务复用优先组合，避免复杂菱形继承。

## Protocol、ABC 与泛型

```python
class Store(Protocol):
    def get(self, task_id: TaskId) -> Task | None: ...
```

Protocol 提供结构化静态多态，对象不必显式继承；ABC 提供运行时名义继承与抽象方法检查。泛型描述类型关系，默认不会产生运行时校验。

Python 多态也来自鸭子类型：只要对象提供调用方需要的行为即可。边界层可用 Protocol 给动态能力增加检查。

- 能解释封装约定、继承、MRO、super 和组合。
- 能区分鸭子类型、Protocol、ABC 与泛型的静态/运行时作用。
