# Python：容器与迭代

Python 容器高度通用，选择时要考虑顺序、可变性、哈希、复杂度和是否会一次性占用内存。

## 常用容器

| 类型 | 适合场景 | 关键点 |
| --- | --- | --- |
| `list` | 默认有序动态序列 | 尾部 append 快，中间插入移动元素 |
| `tuple` | 固定结构、不可变序列 | 元素本身仍可能可变 |
| `dict` | 保持插入顺序的键值映射 | key 必须可哈希且相等/哈希稳定 |
| `set` / `frozenset` | 去重和成员判断 | 无业务排序语义 |
| `deque` | 队列和双端操作 | 两端增删高效 |
| `heapq` | 优先队列 | 在 list 上维护最小堆 |

对外返回内部 list/dict 时明确共享或复制。浅复制只复制外层容器，嵌套对象仍共享。

## iterable、iterator 与 generator

- iterable 可以产生 iterator；iterator 记录一次遍历状态。
- `iter()` 获取 iterator，`next()` 推进并可能抛 StopIteration。
- generator 惰性产生值，适合流式处理和组合管道。
- 生成器持有函数帧和捕获资源，未耗尽时要明确关闭策略。

```python
def read_valid(lines: Iterable[str]) -> Iterator[Record]:
    for line in lines:
        if record := parse(line):
            yield record
```

## 排序与复杂度

`sorted` 返回新 list，`list.sort` 原地修改；排序稳定。成员判断在 list 通常线性，在 set/dict 平均常数。性能判断结合数据规模、对象哈希成本和内存，而不是只背复杂度。

## 验收

- 能按顺序、查找、队列、去重和可变性选择容器。
- 能区分 iterable、iterator、generator 和一次性消费。
- 能避免内部集合泄露、错误浅复制和无意一次性加载大数据。
