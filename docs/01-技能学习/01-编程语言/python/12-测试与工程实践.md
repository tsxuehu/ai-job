# Python：测试与工程实践

Python 的动态性提高迭代速度，也要求把类型检查、运行时校验、测试和生产观测组合成明确门禁。

## 质量门禁

- formatter 与 lint 保持一致风格、导入和错误规则。
- 静态类型检查覆盖核心包，逐步减少 Any 泄漏。
- pytest 执行单元、集成、异步与属性测试。
- CI 固定 Python 和锁定依赖，构建与部署同一产物。

## 测试分层

- 单元测试：领域类型、纯函数、状态转换和错误映射。
- 组件测试：API handler、schema、repository、任务和中间件。
- 集成测试：真实数据库、缓存、模型/HTTP 服务替身与迁移。
- 属性/fuzz 测试：解析器、序列化和不可信输入。
- 并发测试：超时、取消、断连、任务失败和资源关闭。

Mock 只隔离稳定边界，不把 ORM/框架内部实现完整复制到测试中。异步测试结束后检查未完成 Task、连接和线程。

## API/AI 生产基线

- 所有外部输入运行时校验，模型输出也视为不可信数据。
- 外部调用有连接/读取/总超时、重试预算、并发上限和取消。
- 同步 SDK 或 CPU 计算从事件循环隔离。
- 数据库池、任务队列、响应体、缓存和模型并发有容量限制。
- 日志、指标和 trace 覆盖流量、错误、延迟、饱和度、token/成本。
- 支持 readiness/liveness、优雅停机和后台任务等待。

## 综合项目

实现异步任务 API：schema、数据库、外部模型超时、并发限制、取消、错误边界、优雅停机和指标；补齐单元/集成/异步测试并完成事件循环阻塞或内存分析。

## 最终验收

- [ ] 能独立构建、测试、部署和诊断 Python 服务。
- [ ] 能发现并隔离 async 链路中的阻塞 IO 或 CPU 工作。
- [ ] 类型标注、运行时校验和外部协议边界一致。
- [ ] 所有任务、连接、缓存和队列有容量与生命周期策略。
