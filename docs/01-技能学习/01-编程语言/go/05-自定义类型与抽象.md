# Go：自定义类型与抽象

Go 没有 class 和类继承。它用具名类型和 struct 表达数据，用 method 封装行为，用 interface 实现多态，用 embedding 与普通字段完成组合。

## struct、method 与封装

```go
type Service struct {
	store Store // 字段小写，仅包内可访问
}

func NewService(store Store) (*Service, error) {
	if store == nil {
		return nil, ErrMissingStore
	}
	return &Service{store: store}, nil
}
```

构造函数只是命名为 `NewType` 的普通函数，用来验证依赖和建立不变量。值 receiver 会复制 receiver；指针 receiver 可修改对象并避免复制大结构。一个类型的方法集应保持一致选择。

## interface 与多态

```go
type Store interface {
	Save(context.Context, Input) (Task, error)
}
```

类型不声明 `implements`，只要方法集匹配就隐式满足接口。接口由使用方定义并保持小而聚焦；生产实现、内存实现和测试替身都可以被同一调用方使用，这就是运行时多态。

interface 值由动态类型和动态值组成。内部装有 nil 指针时，interface 本身并不等于 nil，这是重要边界问题。

## embedding 不是继承

```go
type AuditedStore struct {
	Store
	logger *slog.Logger
}
```

embedding 会提升字段或方法，方便转发，但不会建立父子类型替换关系；`AuditedStore` 不是 `Store` 实现类型的子类。Go 把数据复用、行为委托和接口多态拆开，避免脆弱继承层级。

## 泛型

泛型适合类型安全的通用容器、算法和适配器；类型约束描述允许的操作。业务依赖替换通常用小接口更直观，不为消除少量重复设计复杂约束。

## 验收

- 能用未导出字段、构造函数和方法维护不变量。
- 能解释值/指针 receiver、方法集和 interface 隐式实现。
- 能说明 Go 如何用组合、接口和泛型替代传统类继承。
