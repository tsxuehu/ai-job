# Go：基础语法

Go 有意保持语言规模较小，并通过统一格式与工具链降低团队协作成本。先学会读程序结构，再进入 slice、interface 和并发等关键语义。

## 最小程序

```go
package main

import "fmt"

func main() {
	port := 8080
	fmt.Printf("listen on %d\n", port)
}
```

- 每个文件属于一个 package；可执行程序使用 `package main` 和 `main` 函数。
- import 在编译期建立 package 依赖，未使用的 import 会编译失败。
- 分号通常由词法规则自动插入，不需要手写。
- 花括号位置受自动分号影响，遵循 `gofmt`，不要自定义排版风格。

## 声明形式

```go
var retries int          // 零值 0
var host = "localhost"   // 推断 string
timeout := 500           // 只允许在函数内部
const maxRetries = 3
```

`var` 可用于包级和函数级声明，`:=` 声明并初始化函数局部变量。包级变量会形成隐藏共享状态，依赖优先显式组装。常量可保持“无类型”直到进入具体上下文。

## 名称、注释与导出

- 名称首字母大写表示可从其他 package 访问，小写表示包内可见。
- 导出 API 的注释应以名称开头并说明契约。
- Go 没有类、注解和传统宏；代码生成通过独立工具执行。
- 一行只表达一个清晰动作，复杂初始化拆出函数。

## 工具基线

从第一天使用 `gofmt`、`go test` 和 `go vet`。编译器拒绝未使用变量和 import，促使代码保持干净，但不能替代业务测试。

## 验收

- 能解释 package、import、main、声明和导出规则。
- 能区分 `var`、`:=`、`const` 的位置和初始化行为。
- 能使用标准工具创建、格式化、编译和运行最小程序。
