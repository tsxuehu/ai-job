# Go：容器与迭代

Go 的核心集合只有 array、slice 和 map；队列、集合、排序等能力通常用它们组合标准库实现。

## array 与 slice

- array 长度固定且属于类型，赋值复制全部元素。
- slice 是底层数组的一段视图，包含长度和容量。
- `append` 可能返回指向新数组的 slice，必须接收返回值。
- subslice 可能长期持有大型数组；仅需少量数据时显式复制。
- 对外返回内部 slice 时要决定共享、只读约定或防御性复制。

```go
result := make([]Task, 0, len(tasks))
for _, task := range tasks {
	if task.Ready() {
		result = append(result, task)
	}
}
```

## map 与 set

- map 的遍历顺序不稳定，输出或测试需要排序键。
- 查询使用 `value, ok` 区分不存在与零值。
- 删除不存在的键是安全的；向 nil map 写入会 panic。
- set 常用 `map[T]struct{}`，也可封装成具名类型隐藏实现。
- map 并发读写不安全，必须用锁、单一 goroutine 所有权或并发容器。

## 迭代与标准库

`range` 产生的是元素值的复制；结构体较大或需要修改原元素时使用索引。排序通常原地修改 slice，API 要说明是否会改变调用方数据。

泛型可抽取常用 map/filter/reduce 类算法，但简单循环往往更符合 Go 可读性。选择抽象要看团队理解成本与复用范围。

## 验收

- 能解释 slice 的长度、容量、共享和扩容行为。
- 能正确处理 map 的零值、查询、顺序和并发限制。
- 能避免暴露内部可变集合、保留大数组和错误修改 range 副本。
