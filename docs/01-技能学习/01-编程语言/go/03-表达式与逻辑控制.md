# Go：表达式与逻辑控制

Go 控制结构少而直接：没有三元表达式，`switch` 默认不贯穿，所有循环统一使用 `for`。

## 表达式

- 算术、比较和逻辑表达式要求类型兼容，`&&`、`||` 会短路。
- `++`、`--` 是语句，不是可嵌入表达式的运算符。
- 多值赋值先计算右侧再赋值，适合交换变量和接收多返回值。
- 类型断言、map 查询和 channel 接收可以使用 `value, ok` 形式区分状态。

```go
value, ok := cache[key]
if !ok {
	return ErrNotFound
}
```

## if 与 switch

```go
if port, err := strconv.Atoi(raw); err != nil {
	return fmt.Errorf("parse port: %w", err)
} else if port <= 0 || port > 65535 {
	return ErrInvalidPort
}
```

`if` 初始化语句中的变量作用域覆盖整个分支结构。`switch` 默认自动 break；只有显式 `fallthrough` 才继续下一分支，而且不会重新判断下一条件。无表达式 `switch` 可替代长 if/else。

## for 与 range

- `for init; condition; post`：经典计数循环。
- `for condition`：条件循环。
- `for {}`：无限循环。
- `for key, value := range collection`：遍历集合或通道。

不要假设 map 遍历顺序稳定。循环变量、闭包和 goroutine 的捕获语义要结合当前 Go 版本理解；显式把本轮值作为参数仍最清晰。

## 控制转移

`break`、`continue`、`return` 可减少嵌套；标签可退出外层循环或 select。`goto` 很少用于业务代码。清理应交给紧邻资源获取位置的 `defer`。

## 验收

- 能使用短路、`value, ok`、if 初始化和 switch 表达分支。
- 能选择不同 `for` 形式并正确处理 map/string 的 range 语义。
- 能用早返回减少嵌套，同时保持错误和资源清理清晰。
