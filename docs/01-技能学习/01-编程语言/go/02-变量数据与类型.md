# Go：变量、数据与类型

Go 的变量和参数都按值复制，但被复制的值内部可能包含指针，因此必须区分“复制描述符”和“复制底层数据”。

## 基础类型和业务类型

- `bool`。
- `int`、`int64`、`uint64` 等；协议和存储字段使用明确宽度。
- `float32`、`float64`；精确金额使用整数最小单位或十进制方案。
- `string` 是不可变字节序列，通常承载 UTF-8 文本。
- `byte` 是 `uint8` 别名，`rune` 是 `int32` 别名，表示 Unicode 标量值。
- 指针保存地址，但普通 Go 代码没有指针运算。

```go
type UserID string
type Timeout time.Duration
```

具名类型可以阻止相同底层类型的业务值被随意混用，并可定义自己的方法。

## 零值与 nil

每种类型都有零值。设计类型时尽量让零值可用；做不到时由构造或方法明确校验。nil pointer 解引用会 panic，nil slice 可读取和 append，nil map 可读取但写入会 panic。

## array、slice 与 map

- array 长度属于类型，赋值会复制整个数组。
- slice 是地址、长度、容量组成的描述值；复制 slice 通常共享底层数组。
- `append` 可能复用原数组，也可能分配新数组，不能依赖隐含共享关系。
- map 是指向运行时结构的描述值，复制后仍访问同一映射；并发读写需要同步。

```go
items := []string{"a", "b"}
counts := map[string]int{"a": 1}
```

## string、byte 与 rune

`range` 字符串时索引是 rune 的起始字节位置，不是第几个字符。协议处理通常按 `[]byte`，Unicode 标量处理按 `range` 或 `[]rune`；用户可见字形还需要更高层 Unicode 库。

## 转换

Go 不做大多数数值隐式转换。显式转换只改变表示，不自动检查溢出和业务范围。字符串与字节切片转换通常会复制，性能敏感路径先用 profile 验证。

## 验收

- 能解释值复制、slice/map 描述值与底层数据的关系。
- 能区分 byte、rune、字节位置和用户字符。
- 能正确处理零值、nil、具名类型和数值范围。
