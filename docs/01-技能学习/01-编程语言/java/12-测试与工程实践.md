# Java：测试与工程实践

Java 后端不能只测试 Spring Controller 正常路径，还要覆盖领域状态、事务、并发、序列化和真实基础设施边界。

## 测试分层

- 单元测试：值对象、领域规则、算法和错误转换。
- 组件测试：Repository、消息处理、序列化和框架配置。
- 集成测试：真实数据库、缓存、HTTP 和事务行为。
- 契约测试：API、事件 schema 和下游兼容。
- 并发/故障测试：超时、取消、重试、重复请求和优雅停机。

Mock 只隔离稳定边界，不用来复刻整个 ORM 或框架。数据库语义使用容器化真实依赖验证。

## 工程门禁

- 固定 JDK、构建工具和依赖版本，CI 执行编译、测试、静态分析和产物构建。
- 开启编译警告、格式和架构规则，拒绝循环依赖与越层调用。
- 数据库迁移、配置和 API schema 随代码版本管理。
- 产物包含版本、依赖清单和可追溯构建信息。

## Spring 生产检查

- 理解 Bean 生命周期、代理边界和事务只在代理调用路径生效。
- 校验外部输入，统一异常映射，不泄露内部堆栈。
- 连接池、线程池、队列、缓存和请求体有容量上限。
- 外部调用有总超时、重试预算、隔离和幂等设计。
- readiness/liveness、指标、日志、trace、优雅停机可用。

## 综合项目

实现任务 API：数据库事务、幂等、线程/虚拟线程容量、外部调用超时、错误映射、优雅停机和指标；完成单元、集成、并发测试及一次 JFR/线程或堆问题分析。

## 最终验收

- [ ] 能独立构建、测试、部署和排障 Java 服务。
- [ ] 能解释事务、代理、线程池、JMM、GC 和类加载边界。
- [ ] 能用 JVM 证据定位一次线程、内存或性能问题。
- [ ] 生产资源有容量、超时、观测和关闭策略。
