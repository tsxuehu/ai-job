# Java

Java 的核心是理解“对象与引用 + JVM 运行时 + 明确的并发可见性 + 成熟工程生态”。快速学习不能只停在 Spring 注解，需要知道对象如何创建、线程如何执行、异常与事务如何传播、JVM 如何观测。

> 开始真实项目之前，先阅读 [Java 项目特性与注意事项](项目注意事项.md)；建立模块化单体或多模块工程时使用 [Java 企业级项目结构](企业级项目结构.md)。

## 七天快速上手

1. 第 1 天：完成基本类型、引用、String、数组和控制流程。
2. 第 2 天：使用 class、record、enum、interface、集合和泛型建模。
3. 第 3 天：训练异常、空值、资源关闭、equals/hashCode。
4. 第 4 天：建立 Maven/Gradle 项目，完成文件、JSON、HTTP 和 JDBC。
5. 第 5 天：实现线程池任务、超时、取消和并发安全状态。
6. 第 6 天：完成 Spring Boot API、校验、事务和集成测试。
7. 第 7 天：使用线程转储、GC 日志和 profiler 定位一次问题。

七天目标是能写并解释一个小型服务；深入掌握还需要真实流量、故障和 JVM 数据。

## 需要学习

- 集合、泛型、异常、反射、注解和类加载。
- Java Memory Model、`volatile`、锁、CAS、并发容器和线程池。
- JVM 内存、垃圾回收、线程转储、堆转储和性能调优。
- Spring Boot、Bean 生命周期、AOP、事务和 Web 请求链路。
- JDBC、连接池、ORM、微服务治理和测试。
- 外部模型调用的超时、流式响应和线程池隔离。

## 验收

开发并排障一个生产级 Spring Boot 服务；能够解释事务、并发、GC 和框架关键机制。

建议验收项目：实现任务 API，包含校验、数据库事务、幂等、线程池隔离、外部调用超时、优雅停机、指标和测试，并完成一次线程或 GC 问题分析。
