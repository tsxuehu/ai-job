# Java：自定义类型、面向对象与抽象

Java 直接支持 class、封装、单继承和接口多态；成熟设计的重点是保护不变量并限制继承造成的耦合。

## 面向对象概念映射

| 概念 | Java 如何实现 |
| --- | --- |
| 对象 | class/record/enum 的实例，通过引用访问 |
| 类 | class 定义字段、构造函数和方法；record/enum/sealed 提供专用建模 |
| 封装 | private/package/protected/public、构造与行为方法 |
| 继承 | class 单继承 `extends`，interface 可多继承契约 |
| 运行时多态 | 方法覆盖、interface/基类引用和动态分派 |
| 编译期多态 | 方法重载、泛型静态检查；泛型多数类型擦除 |
| 组合 | 字段持有依赖并委托，通过构造注入完成替换 |

Java 是典型 class-based OOP 语言，但多态不要求继承实现：面向接口编程与组合通常能降低基类耦合。

## class、record、enum 与 sealed

- class 适合具有身份、生命周期和行为的对象。
- record 适合不可重新绑定字段的数据载体，会生成访问器和基于组件的相等语义。
- enum 表达有限实例，并可包含字段和行为。
- sealed class/interface 显式限制允许的实现，适合可穷举领域状态。

```java
public record TaskId(long value) {
    public TaskId {
        if (value <= 0) throw new IllegalArgumentException("value");
    }
}
```

封装不是批量生成 getter/setter，而是通过构造、方法和最小可见性维护有效状态。

## 继承、组合与接口

class 只能继承一个父类，可以实现多个 interface。继承同时获得实现和子类型关系，只有稳定的 `is-a` 替换关系才使用；复用实现优先组合与委托。

```java
public interface Storage {
    Optional<Task> get(TaskId id);
}
```

接口定义契约并提供运行时多态；依赖注入让生产实现与测试实现替换。抽象基类适合共享受保护的骨架，但避免深继承树。

## 泛型

Java 泛型多数通过类型擦除实现。通配符遵循 PECS：生产数据使用 `? extends T`，消费数据使用 `? super T`。基本类型不能直接作为类型参数，使用包装类型会产生装箱。

## 验收

- 能用构造、私有字段和行为方法维护不变量。
- 能区分 class、record、enum、sealed 类型和 interface。
- 能解释继承、组合、运行时多态、类型擦除和泛型边界。
