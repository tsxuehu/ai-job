# Java：运行时与性能

Java 性能来自 JVM、JIT、GC、类加载、线程和操作系统共同作用；不能用源码行数猜测运行成本。

## JVM 执行过程

```text
源码 → javac 字节码 → 类加载/验证/链接/初始化
→ 解释执行与 JIT 编译 → 本地机器码
```

类加载器定义类型身份；同名类由不同加载器加载也不是同一类型。初始化静态字段或代码块时要避免隐藏 IO、循环依赖和死锁。

JIT 根据运行热点优化、内联和逃逸分析，假设失效时可能去优化。基准需要预热，不能用一次调用衡量稳定性能。

## GC 与性能指标

选择 GC 前先定义堆规模、吞吐、暂停和尾延迟目标。观察分配速率、存活集、晋升、停顿、CPU 和 native 内存，不根据一条 GC 日志调参数。

常见瓶颈包括算法、装箱、对象分配、序列化、锁竞争、连接池、日志和下游 IO。对象池和缓存可能增加存活集与复杂度。

## 分析工具

- JFR/JMC：低开销事件、CPU、分配、锁和 IO 分析。
- 线程转储：死锁、阻塞、线程池饱和。
- 堆转储：对象占用、GC Roots 和保留链。
- GC 日志/native memory tracking：回收与堆外容量。
- JMH：可靠微基准，处理预热和无用代码消除。

## 验收

- 能解释类加载、解释器、JIT、去优化和 GC 的基本关系。
- 能选择线程转储、堆转储、JFR、GC 日志定位不同问题。
- 性能结论包含预热、负载、P95/P99、资源和正确性回归。
