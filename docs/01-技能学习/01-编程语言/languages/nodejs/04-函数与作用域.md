# Node.js / TypeScript：函数与作用域

JavaScript 函数是一等对象，并通过词法环境形成闭包。异步回调和长期监听器会延长捕获对象的生命周期。

## 1. 函数签名

```ts
type Handler<T> = (input: T, signal: AbortSignal) => Promise<Result>;

async function handle(input: Input, signal: AbortSignal): Promise<Result> {
  // ...
}
```

- 参数按值传递；对象参数复制引用值，因此可观察到对象修改。
- 可选参数、默认参数和 rest 参数要区分“未提供”与明确 undefined。
- 重载只影响 TypeScript 调用类型，运行时仍只有一个实现。
- async 函数的同步 throw 会变成 rejected Promise。

## 2. 作用域与闭包

`let`/`const` 是块作用域，`var` 是函数作用域并有提升。闭包保存词法环境中的绑定，不是自动快照；timer、事件监听器和缓存回调可能让大型对象长期可达。

## 3. this 与箭头函数

普通函数的 `this` 由调用方式决定；箭头函数捕获外层 `this`，不能通过 bind/call 改变。把对象方法作为回调传递可能丢失 this，使用 bind、包装箭头函数或避免依赖动态 this。

```ts
class Worker {
  run(): void {}
  start = (): void => this.run();
}
```

## 4. 泛型函数

泛型描述输入输出关系和约束，不产生运行时类型信息。若运行时需要 schema、构造器或判别字段，必须显式传入。

## 5. `async` 函数实际发生什么

```ts
async function checkout(order: Order, gateway: PaymentGateway): Promise<void> {
  const receipt = await gateway.pay(order.id, order.amountCents);
  order.markPaid(receipt.id);
}
```

调用 async 函数会立即得到 Promise。函数先同步执行到第一个真正需要等待的位置，随后把 continuation 安排到 Promise job/microtask。`await` 不创建线程，也不会让前面的 CPU 循环自动让出事件循环。

调用者必须 `await checkout(...)`、`return checkout(...)`，或明确用一个任务管理器持有它；只调用不处理会丢失失败和生命周期。

## 6. 闭包与监听器会保留对象

timer、EventEmitter listener、Promise callback 和缓存函数都可能通过闭包保留整个请求对象。资源结束时应移除监听、取消 timer，并避免为一个小字段捕获大型对象图。

## 7. 泛型不会产生运行时类型

```ts
function decode<T>(text: string): T {
  return JSON.parse(text) as T; // 没有验证，API 名称具有误导性
}
```

若要安全 decode，应接收运行时 schema/parser。泛型只描述“输入输出类型关系”，不应伪装成运行时反序列化保证。

## 8. 与其他语言对照

| 语言经验 | Node.js / TypeScript 中的差异 |
| --- | --- |
| Python async | 都是协作式暂停，但任务调度、取消和库协议不同 |
| Java CompletableFuture | Promise 没有强制错误类型，普通 JS 默认仍在一个事件循环线程执行 |
| Go | async/await 会给调用链着色；Go 阻塞式写法由 runtime 调度 goroutine |

## 9. 动手验证

1. 在 async 函数各位置打印顺序，区分同步段、microtask 和 timer；
2. 调用 rejected Promise 但不等待，再建立统一任务管理；
3. 把类方法直接作为回调，观察 this 丢失并修复；
4. 用 listener 捕获大对象，移除监听后比较 heap snapshot；
5. 把伪泛型 decode 改成接收 runtime parser。

## 10. 掌握标准

- 能解释参数值、闭包绑定和对象共享。
- 能判断普通函数、箭头函数和 this 绑定。
- 能正确传播 async 结果，避免 Promise 丢失和长期闭包保留。
