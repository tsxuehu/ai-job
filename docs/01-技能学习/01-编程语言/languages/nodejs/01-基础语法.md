# Node.js / TypeScript：基础语法

Node.js 是 JavaScript 运行时，TypeScript 是编译期类型检查层。TypeScript 类型通常会被擦除，生产输入必须在运行时重新校验。

## 最小程序

```ts
const port: number = 8080;

function main(): void {
  console.log(`listen on ${port}`);
}

main();
```

- 语句可省略分号，但自动分号插入存在边界；交给格式化工具统一。
- `{}` 是代码块或对象字面量，含义由语法位置决定。
- 模板字符串支持插值和多行文本。
- JavaScript 按运行时值执行；TypeScript 编译错误不会自动变成线上保护。

## 声明与模块

使用 `const` 表示绑定不再重新赋值，确需重新赋值时用 `let`，不使用函数作用域且有提升问题的 `var`。现代服务优先采用 ESM 的 `import`/`export`，项目统一 module 配置。

```ts
import { readFile } from "node:fs/promises";
export type Config = { port: number };
```

## 常见语法设施

- `?.` 可选链和 `??` 空值合并只处理 `null/undefined`，不要与 `||` 的真值逻辑混淆。
- 解构、展开语法适合浅层数据组合，不会自动深复制。
- `async` 函数一定返回 Promise；调用后必须 await、return 或显式管理。
- `#field` 是 JavaScript 运行时私有字段，TypeScript `private` 主要是编译期约束。

## 工具基线

启用 TypeScript `strict`，统一 formatter、lint、类型检查和测试。不要用 `any` 或大范围类型断言消除诊断；它们把错误推迟到运行时。

## 验收

- 能区分 Node.js、JavaScript、TypeScript 和类型擦除。
- 能正确使用 const/let、模块、模板字符串和空值运算符。
- 能建立 strict TypeScript 项目并解释编译期与运行时错误。
