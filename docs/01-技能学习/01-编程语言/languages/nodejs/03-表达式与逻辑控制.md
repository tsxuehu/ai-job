# Node.js / TypeScript：表达式与逻辑控制

JavaScript 隐式转换较多，TypeScript 的控制流分析可以根据分支收窄类型，但前提是运行时判断真实可靠。

## 1. 表达式与转换

- 使用 `===`，避免 `==` 的宽松转换规则进入业务代码。
- `&&`、`||` 返回操作数值，不一定返回 boolean；`??` 只在 null/undefined 时选择右值。
- `+` 同时用于数值加法和字符串拼接，外部输入先校验类型。
- `await` 只能等待 Promise-like 值；并不把同步 CPU 操作变成异步。

## 2. 类型收窄

```ts
function handle(result: Result<Task>): Task {
  switch (result.kind) {
    case "ok":
      return result.value;
    case "error":
      throw result.error;
    default:
      return assertNever(result);
  }
}
```

`typeof`、`instanceof`、`in`、判别字段和自定义 type guard 都能收窄。穷举联合类型时用 `never` 检查新增状态，不能只写一个静默 default。

## 3. 分支和循环

- if/else 适合条件分支，switch 适合离散状态。
- `for...of` 遍历可迭代值，`for...in` 遍历对象可枚举键，不能混用。
- 数组 map/filter/reduce 适合纯数据变换；异步副作用不要直接交给 `forEach(async ...)`。
- 需要串行异步时使用 `for...of + await`，需要并发时显式使用 Promise 组合和并发上限。

## 4. 用判别联合表达订单状态

```ts
type OrderState =
  | { kind: "pending" }
  | { kind: "paid"; paymentId: string }
  | { kind: "cancelled"; reason: string };

function nextAction(state: OrderState): string {
  switch (state.kind) {
    case "pending": return "pay";
    case "paid": return "ship";
    case "cancelled": return "stop";
    default: return assertNever(state);
  }
}
```

判别字段既在运行时存在，又能驱动 TypeScript 收窄。它比 `paid: boolean, cancelled: boolean` 更难表示矛盾状态。外部输入必须先验证，才能安全进入这个联合类型。

## 5. 异步循环必须显式选择串行或并发

```ts
// 错误：forEach 不等待 async callback。
orders.forEach(async (order) => processOrder(order));

// 串行：
for (const order of orders) {
  await processOrder(order);
}
```

并发处理要使用 Promise 组合并设置上限。`Promise.all` 会立即为所有输入创建工作，不适合无界列表；错误时也要明确剩余任务是否继续和如何取消。

## 6. 与其他语言对照

| 语言经验 | JavaScript/TypeScript 中的差异 |
| --- | --- |
| Java/C++/Go | `&&/||` 返回操作数且存在更多隐式转换；业务比较优先 `===` |
| Python | 短路返回操作数类似，但假值集合、相等和数字模型不同 |
| Java sealed type | 判别联合只在编译期建模，运行时靠普通字段 |

## 7. 动手验证

1. 给 OrderState 新增 refunded，验证 assertNever 能否报错；
2. 比较 `||` 与 `??` 对 0、空字符串、null 和 undefined 的结果；
3. 运行 `forEach(async)` 并观察主流程何时结束；
4. 给 Promise.all 输入大量慢任务，观察资源峰值，再加入并发限制；
5. 用 unknown + type guard 建立可信收窄。

## 8. 掌握标准

- 能解释 `===`、真值、`??` 与隐式转换。
- 能用判别联合和 never 完成穷举分支。
- 能正确选择 for-of、数组操作和串/并行异步流程。
