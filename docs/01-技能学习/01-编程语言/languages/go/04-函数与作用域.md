# Go：函数与作用域

Go 函数参数和返回值全部按值传递；指针、slice、map、channel、函数和 interface 的值本身包含对底层数据的引用信息。

## 参数与多返回值

```go
func ParseConfig(raw []byte) (Config, error) {
	// 返回结果和错误
}
```

- 多返回值常表达“结果 + error”或“值 + 是否存在”。
- 可变参数在函数内是 slice；把现有 slice 展开使用 `items...`。
- 对小型、只读值优先传值；需要修改调用方对象时传指针。
- 返回值应表达结果，不通过可变包级变量或隐含输出传递状态。

## 函数值与闭包

函数是一等值，可作为回调、策略和 HTTP 中间件。闭包捕获变量而非永恒快照；跨 goroutine 或延迟调用时要确认捕获数据的生命周期和同步方式。

```go
func WithLogging(next Handler) Handler {
	return func(ctx context.Context, req Request) error {
		return next(ctx, req)
	}
}
```

## 作用域与遮蔽

标识符作用域由代码块、函数、文件和 package 决定。短声明 `:=` 只要同一作用域中至少有一个新变量就成立，可能意外遮蔽外层 `err` 或结果变量。长函数中要特别审查嵌套块。

## defer

`defer` 在外围函数返回前按后进先出执行，实参在注册时求值。它适合关闭资源和解锁，但循环中反复 defer 会让资源直到整个函数结束才释放；可将单次迭代提取成函数。

命名返回值适合简短函数或 defer 修改错误；复杂函数中容易产生隐式行为。

## 验收

- 能解释“全部按值传递”与底层共享并不矛盾。
- 能识别闭包捕获、短声明遮蔽和命名返回值风险。
- 能把 `defer` 放在正确作用域并处理关闭阶段错误。
