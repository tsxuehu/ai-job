# C++：函数与作用域

函数签名应该同时表达输入输出、可空性、是否修改以及是否转移所有权。

## 1. 参数与返回值

```cpp
Result parse(std::string_view input);              // 借用字符数据
void update(Config& config);                       // 修改调用者对象
void inspect(const Config& config);                // 只读借用
std::unique_ptr<Service> create_service(Config);   // 返回独占所有权
```

小型值直接传值；大对象只读借用；需要修改时传非常量引用；允许没有对象时才使用指针或 `optional`。优先通过返回值表达结果，不依赖可变全局状态或隐藏输出参数。

## 2. 重载、默认参数与 constexpr

- 重载适合同一概念的不同输入类型，不应用同名掩盖不同行为。
- 默认参数在调用方编译时展开，公共库修改默认值需要考虑旧调用方。
- `constexpr` 允许满足条件的计算在编译期执行，但仍应保持接口清晰。
- `[[nodiscard]]` 适合不能被静默忽略的状态或错误结果。

## 3. lambda 与捕获

```cpp
auto is_ready = [limit](const Task& task) {
    return task.priority() >= limit;
};
```

明确值捕获和引用捕获。lambda 被异步保存时，按引用捕获局部对象很容易悬垂；捕获 `this` 也不拥有当前对象。

## 4. 作用域、存储期和生命周期

- 块作用域局部对象通常在离开作用域时逆序析构。
- 命名空间作用域对象可能产生跨翻译单元初始化顺序问题。
- 函数内 `static` 对象只初始化一次，但它仍是共享状态。
- `thread_local` 每个线程一份，析构次序和线程池复用都需考虑。
- 名称的作用域、对象的存储期和引用的生命周期是三个不同概念。

## 5. 易错点

- 返回局部对象的引用，或保存比实参活得更久的借用。
- 使用默认参数加虚函数，误判默认值的绑定位置。
- lambda 捕获引用后提交到线程池。
- 滥用静态局部变量，使函数难以测试并引入并发竞争。

## 6. 用结算函数读懂参数语义

```cpp
void checkout(Order& order, PaymentGateway& gateway) {
    gateway.pay(order.id(), order.amount_cents());
    order.mark_paid();
}
```

- `Order&`：借用同一个订单并允许修改；
- `PaymentGateway&`：不拥有网关，通过虚函数调用实现；
- 两个引用都要求调用期间对象仍存活；
- 函数没有接管任何对象的销毁责任。

若函数需要保存 gateway，就不能无条件保存引用；必须把生命周期关系写进对象设计，或接收能表达所有权的类型。

## 7. 返回值、移动和生命周期

```cpp
Order make_order(std::string id, std::int64_t amount) {
    return Order{std::move(id), amount};
}
```

返回值优先于手写输出参数。编译器可以进行 copy elision；即使需要移动，也应让类型保持正确的值语义。不要为了“避免复制”返回局部引用或盲目写 `std::move(local)`，后者还可能阻碍返回值优化。

## 8. 与其他语言对照

| 语言经验 | C++ 中的差异 |
| --- | --- |
| Java | 方法参数只有值和引用值的复制；C++ 签名显式区分 `T`、`T&`、`const T&`、`T*` |
| Python/Node.js | C++ 重载在编译期解析，lambda 捕获还涉及对象生命周期 |
| Go | Go 不支持函数重载；C++ 重载、默认参数和模板可能共同参与解析 |

## 9. 动手验证

1. 为 `Order` 打印 copy/move 构造，比较按值传递和返回；
2. 把异步 lambda 从引用捕获改为安全的值/所有权捕获；
3. 创建歧义重载，分析隐式转换如何参与候选选择；
4. 返回局部引用并用 ASan 验证错误；
5. 将隐藏输出参数重构为明确返回值。

## 10. 掌握标准

- 能让函数签名清楚表达只读、修改、可空和所有权转移。
- 能说明重载、默认参数、lambda 捕获的绑定时机。
- 能区分名称作用域、存储期和对象生命周期。
