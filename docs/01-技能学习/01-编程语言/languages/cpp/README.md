# C++

C++ 的核心不是记住语法，而是持续回答三个问题：对象由谁拥有、生命周期到哪里结束、当前抽象需要付出什么运行时成本。

> 示例基线：C++20。使用 C++23 能力时会单独标注；项目还要固定编译器、标准库、构建参数和依赖版本。

> 动手验证：[运行 C++ 订单示例](../../examples/README.md#可运行订单示例)。

> 完成语言基础后学习 [13-工程化](13-工程化.md)，进入真实项目时再查阅 [14-项目注意事项](14-项目注意事项.md)。

## 七天快速上手

1. 第 1 天：完成语法、类型和引用练习，开启严格编译警告。
2. 第 2 天：使用 `vector`、`string`、`unordered_map` 完成数据处理程序。
3. 第 3 天：实现类、接口和模板函数，明确复制与移动行为。
4. 第 4 天：用 RAII 管理文件、锁和动态对象，注入异常验证资源释放。
5. 第 5 天：建立 CMake 项目，引入测试，完成文件 IO 和序列化。
6. 第 6 天：实现有界线程池或任务队列，验证停止、竞争和背压。
7. 第 7 天：运行 sanitizer、基准测试和 profiler，整理限制与优化证据。

快速上手不等于掌握 C++。完成七天任务后，应继续通过真实组件训练生命周期、并发和性能判断。

## 需要学习

- 指针、引用、对象生命周期、栈和堆。
- RAII、复制/移动语义、智能指针和异常安全。
- STL、模板、迭代器失效和未定义行为。
- 线程、锁、原子操作、内存模型和 data race。
- 编译、链接、CMake、静态库和动态库。
- GDB/LLDB、sanitizer、Valgrind 和 profiler。
- 缓存局部性、SIMD、内存带宽和批处理；专项岗位再学习 CUDA。

## 验收

实现并调试一个高性能服务或基础组件，能定位越界、泄漏、use-after-free、竞争和性能热点。

建议验收项目：实现一个有界并发任务服务，包含配置解析、任务提交、取消、超时、优雅停机、指标和测试。必须使用 AddressSanitizer、UndefinedBehaviorSanitizer 和 ThreadSanitizer 分别验证内存、未定义行为与竞争问题。
