# C++：自定义类型、面向对象与抽象

自定义类型的目标不是把字段装进类，而是建立有效状态、行为边界和可替换的依赖契约。

## 面向对象概念映射

| 概念 | C++ 如何实现 |
| --- | --- |
| 对象 | struct/class 的实例，具有存储期、生命周期和值/身份语义 |
| 类 | `struct`/`class` 定义数据布局、构造、析构和成员函数 |
| 封装 | private/protected/public、构造函数、成员函数与模块边界 |
| 继承 | `class Derived : public Base`，同时涉及实现复用与子类型关系 |
| 运行时多态 | 虚函数、抽象基类、类型擦除，通常通过引用/指针使用 |
| 编译期多态 | 函数重载、模板、Concept、CRTP |
| 组合 | 成员对象、RAII 包装和委托，通常优先于继承 |

C++ 完整支持经典面向对象，但“能继承”不等于“应该继承”。只有派生对象能遵守基类契约并安全替换时，才形成正确子类型。

## struct、class 与 enum

- `struct` 与 `class` 能力基本相同，主要区别是默认可见性和默认继承方式。
- 用构造函数建立不变量，使对象一旦构造完成就是有效状态。
- 用 `enum class` 表达有限状态，避免整数和枚举之间的隐式混用。
- 公共字段适合简单数据载体；需要维护约束时通过成员函数控制修改。

```cpp
class Port {
public:
    static std::optional<Port> parse(int value);
    int value() const { return value_; }

private:
    explicit Port(int value) : value_{value} {}
    int value_;
};
```

## 封装、继承与运行时多态

封装是隐藏表示并保护不变量，不等于“所有字段都写 getter/setter”。优先组合；只有存在稳定的 `is-a` 替换关系时才使用继承。

```cpp
class Storage {
public:
    virtual ~Storage() = default;
    virtual std::optional<Value> get(Key key) const = 0;
};
```

基类用于多态删除时需要虚析构函数。运行时多态通过虚函数或类型擦除实现，适合插件和稳定接口边界。

## 模板、Concept 与静态多态

模板在编译期针对具体类型实例化。Concept 为模板参数提供可读约束，能更早暴露不满足接口的问题。

```cpp
template <typename T>
concept Identifiable = requires(const T& value) {
    { value.id() } -> std::convertible_to<std::string_view>;
};
```

模板可能增加编译时间和二进制体积；虚函数有动态分派和间接访问成本。选择依据是扩展边界和测量结果。

## 易错点

- 公共 setter 允许对象进入无效状态。
- 为复用代码建立深继承树，破坏替换原则。
- 多态基类没有虚析构函数。
- 模板接口没有约束，错误在深层实例化中爆发。

## 验收

- 能用构造和访问控制维护对象不变量。
- 能区分组合、继承、虚函数多态与模板静态多态。
- 能解释 C++ 如何实现封装、继承和多态，以及各自成本。
