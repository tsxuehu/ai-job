# Python：变量、数据与类型

Python 变量不是盒子，而是绑定对象的名称。赋值通常复制引用，是否能观察到变化取决于对象可变性。

## 1. 核心对象类型

- `None`、`bool`、`int`、`float`、`complex`。
- `str` 是 Unicode 文本，`bytes` 是字节序列。
- `tuple`、`frozenset` 等不可变容器。
- `list`、`dict`、`set`、`bytearray` 等可变容器。
- `int` 支持任意精度，但大数仍有时间和内存成本；金额使用 Decimal 或整数最小单位。

## 2. 名称、引用和实际对象

Python 中所有数据都是对象。变量更准确地说是“名称”，赋值让名称绑定到对象，而不是把对象内容放进一个固定类型的变量盒子。

### 2.1 名称绑定到对象

```python
first = 100
second = first
```

可以理解为：

```text
名称 first ──┐
             ├──▶ int 对象 100
名称 second ─┘
```

`int` 不可变。执行下面代码时，不是把 100 改成 200，而是让 `second` 改为绑定另一个对象：

```python
second = 200
```

关系变为：

```text
first  ──▶ int 对象 100
second ──▶ int 对象 200
```

因此 `first` 仍然是 100。

### 2.2 多个名称可以绑定同一个可变对象

```python
first = ["a"]
second = first
second.append("b")
```

关系是：

```text
first  ──引用──┐
               ├──▶ 同一个 list 对象 ["a", "b"]
second ──引用──┘
```

`append` 修改 list 对象本身，所以通过 `first` 也能看到变化。若执行 `second = ["c"]`，则只是让名称 `second` 绑定新列表，不会修改原列表。

### 2.3 函数参数也是新的名称绑定

```python
def add_item(items):
    items.append("new")

names = ["old"]
add_item(names)
```

调用时，形参名称 `items` 和调用者名称 `names` 暂时绑定同一个 list，因此函数内修改 list，调用者能够看到。

```python
def replace(items):
    items = ["new"]

names = ["old"]
replace(names)
print(names)  # ["old"]
```

第二个函数只让局部名称 `items` 绑定新列表，没有改变调用者名称 `names` 的绑定。

### 2.4 浅复制创建新容器，但继续共享内部对象

```python
first = {"address": {"city": "Shanghai"}}
second = first.copy()
second["address"]["city"] = "Beijing"
```

关系是：

```text
first  ──▶ dict 1 ──┐
                     ├──▶ 同一个 address dict
second ──▶ dict 2 ──┘
```

所以 `first["address"]["city"]` 也变成 `Beijing`。

### 2.5 `None` 表示绑定到“没有值”对象

```python
user = None
```

`user` 并不是没有变量，而是绑定到唯一的 `None` 对象。它没有 `User` 的字段和方法，因此必须先判断：

```python
if user is not None:
    print(user.name)
```

### 2.6 Python 不提供普通指针操作

Python 引用由解释器管理，普通代码不能像 C++ 一样解引用或做指针运算。`id(obj)` 表示对象在当前生命周期内的身份，不应把它当成可操作、永久稳定的业务内存地址。解释器根据引用关系和垃圾回收规则管理对象生命周期。

## 3. 身份、相等和可变性

`is` 比较对象身份，通常只用于 `None` 等单例；`==` 比较值语义。不可变对象“修改”会产生新对象；可变对象可被多个名称共享。默认参数和全局缓存中的可变对象尤其容易泄漏状态。

## 4. 类型标注

```python
UserId = NewType("UserId", int)

def find(user_id: UserId) -> User | None:
    ...
```

- `T | None` 显式表达可空。
- `Literal`/Enum 表达有限值，TypedDict 表达字典形状。
- NewType 在静态检查中区分相同底层类型，运行时开销很小。
- `Any` 关闭检查传播，外部数据优先 `object`/unknown 思路并校验。

类型标注不会自动验证 JSON、环境变量和数据库数据，需要 schema/模型层。

## 5. 复制和转换

区分赋值、浅复制和深复制；deepcopy 不一定适合连接、锁和大型对象图。字符串到数值等转换会抛异常，边界层捕获并补充上下文。

## 6. 订单对象中名称如何共享

```python
first = Order("order-1", 100)
second = first
second.mark_paid()

assert first is second
assert first.status is Status.PAID
```

赋值创建/重新绑定名称，不复制 Order。函数调用也把对象绑定给新的形参名称：函数能修改同一个可变对象，重新绑定形参却不会改变调用方名称。

```python
def replace(order: Order) -> None:
    order = Order("other", 200)  # 只重新绑定局部名称
```

## 7. 数据模型比“动态类型”更具体

对象的类型决定 `__eq__`、`__hash__`、`__iter__`、属性访问和调用等协议。`dataclass` 只是为一组常见协议生成方法；是否可变、是否可哈希、相等性是否符合领域身份仍由设计者决定。

不要依赖小整数或字符串驻留来推断 `is`；身份比较通常只用于 `None` 和明确单例。

## 8. 与其他语言对照

| 语言经验 | Python 中必须修正 |
| --- | --- |
| C++/Go 值赋值 | Python 赋值通常只重新绑定名称，不复制对象 |
| Java 引用 | 使用感觉接近，但 Python 名称无声明类型，协议在运行时解析 |
| TypeScript 类型 | Python 标注也默认不校验运行时输入，且对象模型与 JS 不同 |
