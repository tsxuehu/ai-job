# Java：自定义类型、面向对象与抽象

Java 直接支持 class、封装、单继承和接口多态；成熟设计的重点是保护不变量并限制继承造成的耦合。

## 1. 面向对象概念映射

| 概念 | Java 如何实现 |
| --- | --- |
| 对象 | class/record/enum 的实例，通过引用访问 |
| 类 | class 定义字段、构造函数和方法；record/enum/sealed 提供专用建模 |
| 封装 | private/package/protected/public、构造与行为方法 |
| 继承 | class 单继承 `extends`，interface 可多继承契约 |
| 运行时多态 | 方法覆盖、interface/基类引用和动态分派 |
| 编译期多态 | 方法重载、泛型静态检查；泛型多数类型擦除 |
| 组合 | 字段持有依赖并委托，通过构造注入完成替换 |

Java 是典型 class-based OOP 语言，但多态不要求继承实现：面向接口编程与组合通常能降低基类耦合。

## 2. class、record、enum 与 sealed

- class 适合具有身份、生命周期和行为的对象。
- record 适合不可重新绑定字段的数据载体，会生成访问器和基于组件的相等语义。
- enum 表达有限实例，并可包含字段和行为。
- sealed class/interface 显式限制允许的实现，适合可穷举领域状态。

```java
public record TaskId(long value) {
    public TaskId {
        if (value <= 0) throw new IllegalArgumentException("value");
    }
}
```

封装不是批量生成 getter/setter，而是通过构造、方法和最小可见性维护有效状态。

## 3. 继承、组合与接口

class 只能继承一个父类，可以实现多个 interface。继承同时获得实现和子类型关系，只有稳定的 `is-a` 替换关系才使用；复用实现优先组合与委托。

```java
public interface Storage {
    Optional<Task> get(TaskId id);
}
```

接口定义契约并提供运行时多态；依赖注入让生产实现与测试实现替换。抽象基类适合共享受保护的骨架，但避免深继承树。

## 4. 泛型

Java 泛型多数通过类型擦除实现。通配符遵循 PECS：生产数据使用 `? extends T`，消费数据使用 `? super T`。基本类型不能直接作为类型参数，使用包装类型会产生装箱。

## 5. 用支付案例看动态多态

```java
public interface PaymentGateway {
    Receipt pay(String orderId, long amountCents);
}

public final class CheckoutService {
    private final PaymentGateway gateway;

    public CheckoutService(PaymentGateway gateway) {
        this.gateway = Objects.requireNonNull(gateway);
    }

    public void checkout(Order order) {
        var receipt = gateway.pay(order.id(), order.amountCents());
        order.markPaid(receipt.id());
    }
}
```

生产传入 HTTP 支付实现，测试传入 fake。调用处只依赖接口；JVM 根据对象实际 class 选择实现方法。构造注入让依赖和对象有效状态同时建立。

## 6. 组合优先于继承

继承会把实现细节、构造顺序和可覆盖方法带入子类合同。若只是增加日志、重试或缓存，应让包装对象持有 `PaymentGateway next` 并显式委托。只有真正可替换且基类为继承设计并有文档时才使用 class inheritance。

## 7. 泛型解决编译期类型复用

```java
static <T> Optional<T> first(List<T> values) {
    return values.isEmpty() ? Optional.empty() : Optional.of(values.get(0));
}
```

类型擦除意味着不能直接 `new T()`、`T.class` 或 `instanceof T`。需要运行时类型时显式传 `Class<T>`/类型令牌。API 设计遵循“生产者 extends、消费者 super”，但不要用复杂通配符掩盖不清晰的领域模型。

## 8. 与其他语言对照

| 语言经验 | Java 中的差异 |
| --- | --- |
| C++ | Java 没有值对象切片和确定析构；泛型通常擦除而非模板实例化 |
| Go | Java 显式 `implements`；Go 按方法集隐式满足接口 |
| Python/TypeScript | Java interface 是名义类型，运行时 class 元数据仍存在 |

## 10. 掌握标准

- 能用构造、私有字段和行为方法维护不变量。
- 能区分 class、record、enum、sealed 类型和 interface。
- 能解释继承、组合、运行时多态、类型擦除和泛型边界。
