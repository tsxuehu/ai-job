# Java：变量、数据与类型

Java 有基本类型和引用类型。变量始终存放一个值；引用变量的值是“指向对象的引用”，不是对象本身。

## 基本类型

- 整数：`byte`、`short`、`int`、`long`；`char` 是 UTF-16 code unit。
- 浮点：`float`、`double`；精确金额使用 `BigDecimal` 并明确舍入规则。
- 布尔：`boolean`。
- 基本类型赋值按值复制，不可为 `null`。

自动装箱把基本类型转换成 `Integer` 等包装类型，但会引入对象、null 和缓存比较等语义，热点路径也可能增加分配。

## 引用、对象与 String

```java
User first = new User("Alice");
User second = first; // 复制引用，两个变量指向同一对象
```

引用赋值不会复制对象。`String` 对象不可变，拼接大量文本使用 `StringBuilder`；比较内容使用 `equals`，`==` 比较基本值或引用是否相同。

数组是固定长度对象，保存基本值或引用。向上转型与数组协变可能把部分类型错误推迟到运行时，通用容器优先使用泛型集合。

## null 与 Optional

引用可能为 `null`，解引用会抛 `NullPointerException`。核心模型通过构造校验、非空约定和类型注解减少 null。`Optional<T>` 适合方法返回“可能不存在”，通常不用于实体字段、方法参数和所有集合元素。

## 转换和数值边界

- 小范围到大范围可自动拓宽；可能丢失数据的转换需显式强转。
- 强转不会验证业务范围，整数溢出默认回绕，可使用 `Math.*Exact` 检查。
- 引用向下转型前用模式匹配 `instanceof` 或更好的多态设计。

## 验收

- 能解释基本值、引用值、对象和数组的复制行为。
- 能正确使用 `equals`/`hashCode`、String、包装类型和 Optional。
- 能识别 null、装箱、溢出、精度和错误强转风险。
