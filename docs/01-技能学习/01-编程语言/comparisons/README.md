# 五门编程语言横向对比

> 目标：使用同一个后端案例，对比 C++、Go、Java、Node.js/TypeScript、Python 的代码形式和运行语义。

横向对比不是背语法表。十二篇都使用订单服务中的具体问题：输入怎样判断、复制后改了谁、函数传了什么、连接由谁关闭、并发任务怎样取消。

## 三个层次

```text
语言语义
控制、数据、函数、容器、错误、资源、IO、并发、运行时
        ↓
代码设计
面向对象、抽象、测试与调试
        ↓
工程落地
功能模块、仓库结构、构建、测试、发布和运行
```

建议先掌握语言语义，再学习模块和工程结构。否则目录看起来正确，代码仍可能因为共享数据、资源泄漏或取消失效而出问题。

## 阅读方式

每篇不需要同时精读五门语言：

1. 先看开头案例和总览表；
2. 精读自己的主语言；
3. 选择一门辅助语言对照；
4. 最后看项目检查清单；
5. 用同一个案例自己写一遍。

对比时始终回答：

- 代码看起来有什么不同？
- 底层语义有什么不同？
- 哪种差异会在真实项目中产生 Bug？
- 面试时能否用具体案例说明？
