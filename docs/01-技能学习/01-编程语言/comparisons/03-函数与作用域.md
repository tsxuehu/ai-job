# 五门语言的函数与作用域：计算订单总价

> 目标：看懂参数传递、返回值、闭包和异步函数到底保存了什么。

统一函数接收订单项并返回总金额。调用方最关心：函数会不会修改输入、错误怎样返回、闭包会不会保存过期数据。

## 1. 参数传递的真实含义

| 语言 | 参数规则 | 调用方可能观察到修改吗 |
|---|---|---|
| C++ | 值、引用、指针由签名明确 | 传非常量引用/指针时可以 |
| Go | 全部按值复制 | slice、map、pointer 等复制后仍可能共享底层数据 |
| Java | 全部按值复制 | 复制对象引用后可以修改同一对象 |
| Node.js/TS | 全部按值复制 | 对象变量的值是引用，因此可以修改同一对象 |
| Python | 对象绑定给形参 | 可变对象可能被原地修改，重新绑定不影响调用方名称 |

“按值传递”不等于“深复制整个对象”。

## 2. 同一个纯计算函数

### C++

```cpp
Money total(std::span<const Item> items) {
    Money result{};
    for (const auto& item : items) result += item.price * item.quantity;
    return result;
}
```

### Go

```go
func Total(items []Item) Money {
	var result Money
	for _, item := range items {
		result += item.Price * Money(item.Quantity)
	}
	return result
}
```

### Java

```java
Money total(List<Item> items) {
    var result = Money.ZERO;
    for (var item : items) result = result.add(item.price().times(item.quantity()));
    return result;
}
```

### Node.js / TypeScript

```ts
function total(items: readonly Item[]): Money {
  return items.reduce(
    (sum, item) => sum + item.price * item.quantity,
    0,
  );
}
```

### Python

```python
def total(items: Sequence[Item]) -> Money:
    return sum(
        (item.price * item.quantity for item in items),
        start=Money.zero(),
    )
```

签名应让“不修改输入”尽量可见：C++ 使用 `const/span`，TypeScript 使用 `readonly`，Python 使用只读协议类型；Go/Java 主要依靠 API 契约和对象设计。

## 3. 闭包捕获什么

| 语言 | 默认心智模型 | 高频风险 |
|---|---|---|
| C++ | lambda 可按值或按引用捕获 | 异步保存引用后对象已销毁 |
| Go | 闭包捕获变量 | 共享变量的数据竞争、循环值语义受版本影响 |
| Java | 捕获 final/effectively final 的值 | 捕获的引用仍指向可变对象 |
| Node.js/TS | 保存词法环境中的绑定 | timer/listener 长期保留大对象 |
| Python | 保存自由变量绑定 | 循环闭包晚绑定、长期持有资源 |

跨线程、goroutine、Task 或回调保存闭包时，要同时检查生命周期和同步，不要只看语法能否编译。

## 4. 异步函数不是普通返回值

- C++ 协程返回框架定义的 awaitable，调度和生命周期由运行时/执行器决定。
- Go 通常由调用方使用 `go` 启动函数；函数本身没有 async 标记。
- Java Future/CompletableFuture 把结果和失败保存在任务对象中。
- TypeScript `async` 一定返回 Promise，同步 throw 会成为 rejection。
- Python `async def` 调用后先得到 coroutine，必须 await 或交给 TaskGroup。

## 5. 项目检查

- 签名是否表达只读、修改、可空、错误和取消？
- 返回集合是否泄露内部可变状态？
- 默认参数是否隐藏时间、随机数或可变对象？
- 闭包是否比被捕获对象活得更久？
- 异步返回值是否被等待、返回或交给明确所有者？

## 6. 面试怎么问

**Java、Go、JavaScript 都说按值传递，为什么对象仍会被改？** 被复制的值中保存了对象或底层数据的引用；复制引用不会复制对象。

**闭包会复制变量吗？** 不能一概而论。C++ 捕获列表显式区分，其他语言通常保存绑定或引用语义；必须结合语言规则和对象可变性回答。

**async 函数为什么容易丢错误？** 失败被保存在 Promise/Future/Task 中；调用方不等待或不观察结果，错误就离开正常调用链。
