# Go 常见面试题与答案

这份题库面向后端 Go 岗位，从语言基础逐步进入并发、运行时、工程化和系统设计。

面试时不要只背名词。一个完整回答通常包含：

```text
先说结论
→ 再解释原理
→ 给一个代码或项目案例
→ 最后说适用边界和常见错误
```

## 2. 面试准备顺序

```text
1. 先掌握 1—3 章，能写出正确基础代码
2. 重点练习第 4 章，能解释任务生命周期
3. 用第 5 章工具实际排查 CPU、内存和 goroutine
4. 结合第 6—7 章写一个可测试、可停机的服务
5. 用第 8 章的结构复盘自己的真实项目
```

资深岗位的判断标准不是能否背出所有运行时名词，而是能否建立清晰的并发和资源边界，在故障时用指标、profile 和 trace 找到证据，并说明架构取舍。
