# Node.js / TypeScript 面试题：V8、内存与性能

## 1. V8 为什么会对代码做 JIT 优化？什么会导致去优化？

**答案：** V8 根据运行时收集到的类型和调用信息优化热点代码，例如对象形状长期稳定时可快速访问属性。当同一热点位置不断出现不同形状或类型，某些优化假设失效，就可能去优化。业务开发先写清楚、再用 profile 找热点；不要凭听说手工迎合 JIT。

## 2. `heapUsed`、`external` 和 RSS 有什么区别？

**答案：** `heapUsed` 主要是 V8 JavaScript 堆中已使用部分；`external` 包含绑定到 JS 对象但位于堆外的内存，Buffer 常涉及这里；RSS 是进程当前驻留物理内存，还包括代码、线程栈和本地库。只盯 heapUsed 会漏掉 Buffer、原生插件和 allocator 等问题。

## 3. 什么是事件循环延迟？它和 CPU 使用率有什么关系？

**答案：** 事件循环延迟表示一个已经可以执行的回调实际等了多久。同步计算、超大 JSON 解析、灾难性正则和过长微任务链都会使它上升；即使进程总 CPU 看起来没有打满，单个事件循环线程也可能已成为瓶颈。应同时观察延迟分位数、CPU profile 和请求 trace。

## 4. Node.js 服务内存持续增长怎么排查？

**答案：** 先区分 V8 堆、Buffer/外部内存还是 RSS 其他部分，再比较不同时间的 heap snapshot，看持续增长对象及其 retaining path。结合请求量检查缓存、监听器、队列、闭包和未结束 Promise。快照会增加停顿和内存，应先在可控环境复现，线上取证要评估余量。
