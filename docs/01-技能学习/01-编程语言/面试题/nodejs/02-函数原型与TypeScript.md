# Node.js / TypeScript 面试题：函数、原型与 TypeScript

## 1. 什么是闭包？它为什么可能造成内存问题？

**答案：** 函数引用了外层作用域变量，并在外层函数结束后仍可使用这些变量，这组函数和环境就是闭包。闭包适合封装状态和生成回调；但长期存活的监听器、定时器若捕获大对象，也会让整条引用链无法回收。排查时要看谁长期持有回调，而不是把闭包本身当成错误。

## 2. 普通函数和箭头函数的 `this` 有什么不同？

**答案：** 普通函数的 `this` 由调用方式决定，脱离对象传递后可能变成 `undefined` 或其他对象；箭头函数没有自己的 `this`，而是捕获定义位置的 `this`。因此箭头函数适合保留外层上下文，但不适合作为需要动态接收者的方法，也不能用作构造函数。

## 3. JavaScript 的 `class` 和原型是什么关系？

**答案：** `class` 是构建原型链和构造函数的一套更清晰语法。实例方法通常位于 `ClassName.prototype` 上，实例通过原型链查找；`extends` 建立继承关系。运行时多态来自对象上的方法查找，并不是像 Java 那样依赖静态类型声明。后端领域建模通常优先组合，继承只表达稳定的 is-a 关系。

## 4. TypeScript 类型在运行时还存在吗？

**答案：** 大多数类型会在编译后擦除，接口、泛型和联合类型不会自动校验 HTTP JSON。TypeScript 保护的是编译时能看到的代码，外部输入仍须使用 schema 或明确代码做运行时解析。它采用结构类型：成员形状兼容即可赋值，这很灵活，但订单 ID、用户 ID 等同为 `string` 的值可用 branded type 避免混用。
