# Node.js / TypeScript 面试题：模块、错误与资源

## 1. ESM 和 CommonJS 的主要区别是什么？

**答案：** ESM 使用 `import/export`，依赖结构可静态分析，支持顶层 `await`；CommonJS 使用 `require/module.exports`，加载模型和互操作规则不同。项目应通过 `package.json`、文件扩展名和构建配置统一模块体系，不能只改一行 import 就假设第三方包、测试器和发布产物都会兼容。

## 2. 应该在哪一层捕获错误？

**答案：** 只有能够恢复、增加业务语义或转换协议响应的边界才捕获。底层保留原始 `cause`，业务层转换为稳定错误类型，HTTP 边界统一映射状态码并记录上下文。不要 `catch` 后只打印并继续，也不要把未知错误原样返回给客户端；进程级未捕获错误不能当作正常业务流程。

## 3. `AbortController` 解决什么问题？

**答案：** Promise 本身没有通用取消能力，`AbortSignal` 用来把取消意图传给支持它的 fetch、计时器或自定义异步函数。客户端断开、请求超时或服务关闭时，应向下游传播同一个或关联 signal，并在收到取消后停止新工作、释放资源。取消是协作式的，忽略 signal 的任务仍会继续运行。

## 4. Node.js 中哪些资源容易泄漏？

**答案：** 常见的有未移除的事件监听器、未清理的 interval、没有消费或销毁的 Stream、悬挂 socket、无上限缓存和永不结束的异步任务。GC 只能处理不可达的 JavaScript 对象，不能替代连接池归还和协议级关闭。资源的创建位置应同时能看出超时、关闭和失败清理路径。
