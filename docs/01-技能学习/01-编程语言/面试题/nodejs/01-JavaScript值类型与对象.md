# Node.js / TypeScript 面试题：JavaScript 值、类型与对象

## 1. JavaScript 的基本类型和对象在赋值时有什么区别？

**答案：** `number`、`string`、`boolean`、`bigint`、`symbol`、`undefined`、`null` 是基本类型，赋值复制值。对象、数组和函数赋值时复制的是指向同一对象的引用值，所以通过任一变量修改对象，另一变量也能看到。函数参数同样按值传递，只是对象参数传入的值恰好是引用。

## 2. `==` 和 `===` 有什么区别？项目中应该用哪个？

**答案：** `==` 会先做隐式类型转换，规则复杂，例如 `"0" == 0` 为真；`===` 不转换类型，类型和值都相同才为真。项目默认使用 `===`，需要转换时显式调用 `Number`、`String` 等。少数代码会用 `value == null` 同时判断 `null` 和 `undefined`，但应通过规范明确约定。

## 3. `null`、`undefined` 和“属性不存在”有什么区别？

**答案：** `undefined` 常表示没有赋值或函数没有返回值，`null` 通常是程序主动表达“没有对象”。读取不存在的普通属性也得到 `undefined`，但可以用 `Object.hasOwn(obj, key)` 区分属性不存在与属性存在但值为 `undefined`。API 边界应明确缺失、空值和删除各自的语义。

## 4. 展开运算符能完成深拷贝吗？

**答案：** 不能。`{ ...source }` 和 `[...items]` 只复制第一层，嵌套对象仍被共享。普通可序列化数据可考虑 `structuredClone`；类实例、函数和特定资源需要按业务定义复制方式。很多场景并不需要深拷贝，更好的做法是明确所有权并只复制要修改的路径。
