# C++ 面试题：值、引用与对象生命周期

## 1. 左值、右值和值类别在项目中有什么意义？

**答案：**

值类别主要影响表达式能否被寻址、能否绑定到某种引用，以及是否可以移动资源。有稳定身份的对象表达式通常是左值，临时结果通常是右值。

面试时不必只背 lvalue/xvalue/prvalue 定义，应能说明：`T&&` 为什么可以接收可移动对象，`std::move` 为什么本身不移动数据，它只是把表达式转换为可用于移动的值类别。

## 2. 指针和引用有什么区别？

**答案：**

指针是可以重新赋值的对象，可以为 `nullptr`，也可以参与指针运算。引用是已有对象的别名，初始化后不能改为引用其他对象。

API 中“必须存在、不转移所有权”常用引用；“可选对象”可用指针或其他显式可选类型。裸指针和引用默认都不应暗示拥有所有权。

## 3. `const` 保证了什么？

**答案：**

`const` 限制通过当前表达式修改对象，帮助表达只读 API。`const T*` 是指向 const T 的指针，`T* const` 是不能改变指向的指针。

`const` 不自动保证深层不变性和线程安全。对象可能通过其他非 const 别名被修改，`mutable` 成员也可在 const 方法中修改。

## 4. 复制和移动有什么区别？移动后的对象能用吗？

**答案：**

复制创建独立状态；移动允许新对象接管旧对象持有的资源，避免深拷贝。移动后对象仍必须处于可析构、可重新赋值的有效状态，但具体内容通常未指定。

项目中对移动后对象只做析构、赋新值或文档明确允许的操作。不要假设所有移动后容器都一定为空。
