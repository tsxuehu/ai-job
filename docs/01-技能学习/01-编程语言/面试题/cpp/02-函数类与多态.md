# C++ 面试题：函数、类与多态

## 1. 重载、覆盖和名称隐藏有什么区别？

**答案：**

重载是同一作用域中同名函数具有不同参数列表，由编译器选择。覆盖是派生类重新实现基类虚函数，应使用 `override` 让编译器检查签名。

派生类声明一个同名方法可能隐藏基类的所有同名重载，可用 `using Base::func;` 引入。返回类型通常不能单独用于区分重载。

## 2. 虚函数多态大致如何实现？

**答案：**

常见实现会在多态对象中保存虚表指针，指向类型的虚函数表。通过基类指针或引用调用虚函数时，程序从表中取得具体函数地址。

vptr/vtable 是主流 ABI 实现方式，不是 C++ 语言强制的对象布局。编译器在知道具体类型时还可能去虚拟化并直接调用。

## 3. 为什么多态基类的析构函数通常要是 virtual？

**答案：**

如果通过基类指针删除派生类对象，基类析构函数不是 virtual 会产生未定义行为，派生类资源可能没有释放。

设计原则是：基类要么允许多态删除并提供 public virtual 析构，要么禁止通过基类删除，使析构函数为 protected 且非 virtual。

## 4. 什么是对象切片？如何避免？

**答案：**

把派生类对象按值赋给基类对象时，只保留基类子对象，派生部分被切掉。之后即使调用虚函数，该对象的动态类型也已是基类。

多态对象通常通过引用、指针或 `unique_ptr<Base>` 传递。如果需要值语义的多态，可使用 variant、类型擦除或显式 `clone` 设计。
