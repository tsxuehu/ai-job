# Java 常见面试题与答案

题库以现代 Java 后端开发为背景，重点考查语言语义、并发正确性、JVM、Spring 和生产问题排查。不要只背术语，要能说明它在项目中会造成什么结果。

| 分类 | 重点 |
| --- | --- |
| [1. 类型、对象与面向对象](01-类型对象与面向对象.md) | 参数传递、相等性、不可变对象和多态 |
| [2. 集合、泛型与 Stream](02-集合泛型与Stream.md) | 容器选择、HashMap、类型擦除和流处理 |
| [3. 异常、资源与语言机制](03-异常资源与语言机制.md) | 异常边界、资源关闭、反射和 Optional |
| [4. 并发与 Java 内存模型](04-并发与Java内存模型.md) | 可见性、原子性、线程池和虚拟线程 |
| [5. JVM、GC 与性能](05-JVM与GC性能.md) | 内存区域、类加载、垃圾回收和诊断 |
| [6. Spring、数据库与事务](06-Spring数据库与事务.md) | 代理、事务、ORM 和连接池 |
| [7. 工程化、测试与安全](07-工程化测试与安全.md) | 模块边界、测试分层、可观测性和安全 |
| [8. 场景题与项目深挖](08-场景题与项目深挖.md) | 故障定位、幂等设计和项目表达 |

建议先独立回答，再对照答案；场景题按“现象 → 证据 → 原因 → 处理 → 验证”组织。
