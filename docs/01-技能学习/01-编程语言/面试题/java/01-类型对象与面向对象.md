# Java 面试题：类型、对象与面向对象

## 1. Java 是值传递还是引用传递？

**答案：** 永远是值传递。基本类型传入的是数值副本；对象变量中保存的是引用，传参时复制的也是这个引用。方法可以通过引用修改同一个对象，却不能把调用者的变量改为指向另一个对象。

```java
void reset(User user) {
    user.setName("new"); // 调用者能看到：修改了同一个对象
    user = new User();   // 调用者看不到：只改了局部引用副本
}
```

## 2. 为什么重写 `equals` 通常必须同时重写 `hashCode`？

**答案：** `HashMap`、`HashSet` 先用哈希值找桶，再用 `equals` 判断是否相等。两个对象若 `equals` 为 `true`，哈希值必须相同；否则相等对象可能落入不同桶，出现查不到或重复保存。作为 key 的字段还应尽量不可变，放入 Map 后修改字段也会破坏查找。

## 3. 怎样设计不可变对象？`record` 是否天然深度不可变？

**答案：** 类型本身不能被继承或改写状态，字段只在构造时赋值，不暴露修改方法；对可变集合要防御性复制，返回时也不能泄露可变引用。`record` 只保证字段引用不能重新赋值，是浅不可变；字段若是 `List`，列表内容仍可能改变。

```java
record Order(List<String> items) {
    Order { items = List.copyOf(items); }
}
```

## 4. 重载和重写有什么区别？多态调用如何确定？

**答案：** 重载是同名、不同参数列表，编译器根据变量的静态类型和参数选择方法；重写是子类提供父类实例方法的新实现，运行时根据对象的实际类型分派。`static`、`private` 方法不参与这种运行时多态，字段访问也不具备多态性。
