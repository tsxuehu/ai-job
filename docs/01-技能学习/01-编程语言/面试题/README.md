# 编程语言面试题

面试题按语言和知识类别拆分。每道题都附答案，既说明语言规则，也说明它在后端项目中的实际影响。

| 语言 | 题目重点 | 入口 |
| --- | --- | --- |
| C++ | 生命周期、RAII、模板、并发与性能 | [C++ 面试题](cpp/README.md) |
| Go | slice、interface、error、goroutine、运行时和服务治理 | [Go 面试题](go/README.md) |
| Java | 集合泛型、JMM、JVM、Spring、事务和诊断 | [Java 面试题](java/README.md) |
| Node.js/TypeScript | 动态语义、事件循环、Promise、Stream、V8 和工程安全 | [Node.js/TypeScript 面试题](nodejs/README.md) |
| Python | 对象模型、协议、GIL、asyncio、CPython 和工程实践 | [Python 面试题](python/README.md) |

## 1. 怎么使用

1. 先遮住答案，用 1～3 分钟说清概念、原理和项目影响。
2. 再对照答案，补上遗漏的边界条件和故障表现。
3. 场景题按“现象 → 证据 → 原因 → 处理 → 验证”回答。
4. 把第 8 类中的通用答案替换成自己项目的真实数据和决策。

会背定义只够回答基础追问。资深岗位更关心：为什么这样设计、错误时会发生什么、怎样用数据证明判断。
