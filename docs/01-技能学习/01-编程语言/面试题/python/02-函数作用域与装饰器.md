# Python 面试题：函数、作用域与装饰器

## 1. Python 函数参数是值传递还是引用传递？

**答案：** 调用时，形参名称绑定到调用者传入的同一个对象，可称为 call by sharing。函数能修改可变对象的内容，但给形参重新赋值不会改变调用者的名称绑定。回答时最好直接描述这个行为，避免“值传递/引用传递”术语造成歧义。

## 2. 为什么不能随意使用可变对象作为默认参数？

**答案：** 默认参数在函数定义时只创建一次，之后每次调用共享同一对象，列表内容会累积。通常用 `None` 表示未提供，再在函数内创建新对象。

```python
def add(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## 3. LEGB、`global` 和 `nonlocal` 分别是什么？

**答案：** 名称查找按 Local、Enclosing、Global、Builtins 顺序进行。在函数内赋值默认创建局部名称；`global` 声明修改模块级名称，`nonlocal` 声明修改最近的外层函数作用域名称。项目代码应少依赖可变全局状态，否则测试隔离和并发推理都会变难。

## 4. 装饰器是什么？实现时要注意什么？

**答案：** 装饰器接收函数或类并返回替代对象，常用于日志、授权、缓存和重试。函数装饰器通常需要 `functools.wraps` 保留名称、文档和签名；异步函数要由异步 wrapper `await`。装饰顺序、异常传播和是否重复执行副作用都必须明确。
