# Python 面试题：场景题与项目深挖

## 1. asyncio 服务的所有请求偶尔同时变慢，怎么排查？

**答案：** 先看事件循环延迟、慢请求 trace 和任务堆栈，检查同步数据库驱动、`time.sleep`、大 JSON、压缩、CPU 计算以及长时间未让出控制权的循环。确认后换异步依赖、分块处理，或将受控的阻塞工作移到线程/进程。不能只增加 worker 掩盖单进程持续阻塞。

## 2. `asyncio.create_task` 创建的任务越来越多，是什么问题？

**答案：** 通常是生产速度超过消费速度，或任务没有所有者、超时和等待点。先统计任务状态并检查它们等待的资源，再改为 `TaskGroup` 或有界队列，限制在途数量并规定失败、取消和关闭行为。只保存任务到全局集合虽能避免过早回收，却不能解决生命周期和过载。

## 3. 多进程 Worker 的内存持续上涨，如何判断原因？

**答案：** 分别观察单 Worker 随请求增长情况和总进程数，使用 `tracemalloc`/对象统计定位 Python 堆，再检查原生扩展、缓存和大响应。临时设置处理一定请求后重启 Worker 可以限制影响，但只是止损；根治仍需找到持有引用或原生分配路径，并以稳定压测验证。

## 4. 面试中怎样讲一个 Python 项目优化案例？

**答案：** 交代业务规模、SLO 和自己的职责，用 profile、trace、SQL 次数、内存快照等证据说明瓶颈；解释算法、批处理、异步化、缓存或多进程方案为何适合，以及一致性和失败风险；最后给出 P95/P99、吞吐、内存或成本变化。不要只说“Python 慢，所以加机器”。
