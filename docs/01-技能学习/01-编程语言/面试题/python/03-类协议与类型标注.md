# Python 面试题：类、协议与类型标注

## 1. Python 多继承的方法查找顺序是什么？`super()` 指谁？

**答案：** Python 用 MRO 确定类及父类的线性查找顺序，可通过 `Class.__mro__` 查看。`super()` 不是简单地“调用直接父类”，而是沿当前 MRO 调用下一个实现。协作式多继承要求相关方法使用兼容签名并继续调用 `super()`；业务代码通常优先组合以降低复杂度。

## 2. `property` 为什么能把方法表现成属性？

**答案：** `property` 实现了描述符协议。属性查找时，类上的描述符可以接管读取、赋值和删除，从而执行校验或计算。函数成为实例方法也依赖描述符绑定 `self`。属性访问应保持轻量且少副作用，昂贵 IO 不应伪装成普通字段读取。

## 3. 鸭子类型和 `Protocol` 有什么关系？

**答案：** 鸭子类型关注对象能做什么，而不是它继承自谁；只要提供所需方法即可协作。`typing.Protocol` 把这种结构要求写成可被静态检查器验证的合同，实现类不必显式继承它。它适合为支付网关、仓储等依赖定义最小接口，同时保留 Python 的结构化灵活性。

## 4. 类型标注会在运行时自动校验吗？

**答案：** 通常不会。解释器不会因为参数标成 `int` 就拒绝字符串；标注主要供静态检查器、IDE 和框架读取。HTTP、消息、配置等外部数据仍需运行时解析。`Any` 会绕过大量检查，应集中在确实动态的边界，并尽快转换为明确类型。
