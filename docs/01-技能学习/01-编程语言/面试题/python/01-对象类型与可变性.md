# Python 面试题：对象、类型与可变性

## 1. Python 变量里保存的是什么？

**答案：** 更准确地说，变量名绑定到对象。`b = a` 让两个名称绑定同一个对象，不会自动复制；随后是修改对象还是把名称重新绑定到新对象，结果不同。理解名称、对象和引用关系，比简单说“引用传递”更准确。

```python
a = [1]
b = a
b.append(2)  # 修改同一个列表，a 也是 [1, 2]
b = [3]      # b 重新绑定，不影响 a
```

## 2. 可变对象和不可变对象有什么区别？

**答案：** 列表、字典、集合通常可原地改变；整数、字符串、元组等不能改变自身，所谓修改会创建或绑定另一个对象。元组本身不可变，但其中若保存列表，列表内容仍可变化。可哈希对象要求其哈希相关状态稳定，因此可变列表不能直接作为字典 key。

## 3. `is` 和 `==` 有什么区别？

**答案：** `is` 判断两个名称是否指向同一个对象，`==` 调用相等性协议比较值。判断 `None` 应使用 `is None`；业务值通常使用 `==`。不要依赖小整数或短字符串可能被缓存的实现细节来使用 `is` 比较数值。

## 4. 浅拷贝和深拷贝有什么区别？

**答案：** 浅拷贝创建新的外层容器，但内部对象仍共享；深拷贝递归复制对象图，可能昂贵，也不一定符合连接、锁、文件和领域实体的业务语义。优先明确哪些层需要独立，构造新的目标对象；只有对象图确实可复制时才使用 `copy.deepcopy`。
