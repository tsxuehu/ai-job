# Python 面试题：运行时、内存与性能

## 1. CPython 如何回收对象？循环引用怎么办？

**答案：** CPython 主要用引用计数，对象引用数归零时通常立即释放；分代循环垃圾回收器负责发现一组相互引用但外部不可达的对象。`del name` 只是删除一个名称绑定，不保证对象立即消失。文件和连接仍应由上下文管理器确定性关闭。

## 2. Python 有 GC，为什么进程内存还会增长？

**答案：** 对象可能仍被缓存、全局集合、闭包、任务或 traceback 引用；即使对象已释放，Python 分配器或系统 allocator 也未必立刻把内存归还 OS。此外 NumPy、图像库和驱动可能在 Python 堆外分配。要先区分 Python 对象增长、原生内存和内存碎片。

## 3. Python 性能优化的正确顺序是什么？

**答案：** 先定义吞吐、延迟或成本目标并稳定复现，再用采样 profiler、`cProfile`、SQL/trace 或 `tracemalloc` 找到真正热点。优先改算法、减少 IO 次数和对象创建，再考虑缓存、批处理、并发或原生扩展。微基准要隔离预热、数据规模和外部抖动，并用端到端指标复验。

## 4. 自由线程（free-threaded）Python 是否意味着以后不用管线程安全？

**答案：** 不意味着。较新的 CPython 提供可选的自由线程构建，使多个线程可并行执行 Python 代码，但它不是所有环境的默认形态，部分扩展还可能不兼容或重新启用 GIL。没有 GIL 后，共享可变状态更需要明确的锁、不可变数据或消息传递；采用前必须验证依赖、性能和部署工具链。参见 [Python 官方自由线程说明](https://docs.python.org/3/howto/free-threading-python.html)。
