# 编程语言

## 学习策略

- 主语言：不用 AI 也能独立编码、测试、调试和优化。
- 辅助语言：能够完成真实服务并参与代码评审。
- 其他语言：能够阅读代码并理解适用场景。

## 语言选择

| 方向 | 推荐组合 |
| --- | --- |
| 企业后端 | Java + Python |
| 云原生、平台、网关 | Go + Python |
| AI Web 产品 | Node.js/TypeScript + Python |
| 推理与高性能基础设施 | C++ + Python |

理解 class、interface、继承、组合与多态时，参见 [五门语言如何实现面向对象](comparisons/object-oriented-programming.md)。学习架构边界时，参见 [五门语言的模块化设计对比](comparisons/modularity.md)；落地完整仓库时，参见 [企业级后端项目工程结构](../../03-实战项目/企业级项目工程结构.md)。

每门语言使用独立目录，目录名保持 ASCII，入口统一为 `README.md`。每个目录包含十二篇公共分类文档、项目注意事项和语言专属企业工程结构；首页给出七天路线和综合项目。

五门语言都按相同的十二类组织：

| 顺序 | 分类 | 学习时要回答的问题 |
| ---: | --- | --- |
| 1 | 基础语法 | 程序、声明、作用域块和工具链最小规则是什么？ |
| 2 | 变量、数据与类型 | 变量保存什么，赋值会复制、移动还是共享什么？ |
| 3 | 表达式与逻辑控制 | 表达式如何求值，状态和分支是否完整？ |
| 4 | 函数与作用域 | 参数如何传递，闭包捕获什么，数据能活多久？ |
| 5 | 自定义类型、面向对象与抽象 | 对象、封装、继承、组合和多态在该语言中如何实现？ |
| 6 | 容器与迭代 | 容器拥有什么，迭代、修改、顺序与复杂度如何？ |
| 7 | 错误处理 | 失败如何表示、传播、转换、记录和恢复？ |
| 8 | 内存与资源 | 对象、文件、连接和任务由谁释放，何时释放？ |
| 9 | 模块化、依赖与 IO | 如何划分边界、控制依赖、组织构建并治理外部数据？ |
| 10 | 并发与异步 | 任务由谁调度、取消、等待，如何同步与背压？ |
| 11 | 运行时与性能 | 代码如何执行，分配、GC、调度和热点成本在哪？ |
| 12 | 测试与工程实践 | 如何证明正确、定位故障并满足生产运行要求？ |

十二类用于横向建立统一认知；每门语言另外保留两篇项目专项：“项目特性与注意事项”集中语言专有语义和高频陷阱，“企业级项目结构”说明该语言的仓库、模块、构建、测试与部署组织。两篇专项都不计入公共分类。

学习新语言时先找与主语言相同的概念，再重点理解语义不同之处。例如“赋值”在 C++ 可能复制或移动，在 Go/Java/Python/JavaScript 中又有不同的值与引用共享规则。

## 掌握标准

主语言需要掌握语法与标准库、运行时、并发、内存、错误处理、资源释放、依赖、测试和性能分析。能实现包含数据库、缓存、超时、取消、日志和测试的服务，并定位 CPU、内存、阻塞与并发问题。
