# 编程语言

## 学习策略

- 主语言：不用 AI 也能独立编码、测试、调试和优化。
- 辅助语言：能够完成真实服务并参与代码评审。
- 其他语言：能够阅读代码并理解适用场景。

## 语言选择

| 方向 | 推荐组合 |
| --- | --- |
| 企业后端 | Java + Python |
| 云原生、平台、网关 | Go + Python |
| AI Web 产品 | Node.js/TypeScript + Python |
| 推理与高性能基础设施 | C++/Rust + Python |

## 掌握标准

主语言需要掌握语法与标准库、运行时、并发、内存、错误处理、资源释放、依赖、测试和性能分析。能实现包含数据库、缓存、超时、取消、日志和测试的服务，并定位 CPU、内存、阻塞与并发问题。
