# Rust：变量、数据与类型

Rust 的绑定默认不可变；类型系统同时描述数据形状、所有权和部分有效状态。

## 绑定与可变性

```rust
let timeout = 500;       // 默认不可变
let mut retries = 0;     // 允许修改当前绑定
retries += 1;

let input = "42";
let input: u32 = input.parse()?; // shadowing，新绑定可以改变类型
```

`mut` 表示允许修改，不代表可以无同步地跨线程共享。`const` 必须声明类型并由编译期表达式初始化；shadowing 创建新绑定，不是修改原值。

## 核心数据类型

- 整数与浮点：`i32`、`u64`、`f64` 等，宽度明确。
- `bool` 与 `char`；`char` 是 Unicode 标量值，不是字节。
- tuple 表达固定数量异构数据，array 表达固定长度同构数据。
- `String` 拥有可增长 UTF-8 数据，`&str` 是借用字符串切片。
- `Vec<T>` 拥有动态序列，`&[T]` 是借用的连续视图。
- `Option<T>` 显式表达可能没有值，没有普遍存在的 null 引用。

字符串不能直接按整数索引。必须明确是在处理字节、Unicode 标量还是更高层的字形。

## move、Copy 与 clone

赋值和按值传参默认移动非 `Copy` 值；整数等简单类型通常实现 `Copy`。`clone()` 是显式复制，可能分配和深拷贝，不能为了绕开借用检查器随意使用。

```rust
let first = String::from("task");
let second = first;        // 所有权移动
// println!("{first}");   // 编译错误
```

## 转换与溢出

- 无损语义转换优先 `From`/`Into`。
- 可能失败的转换使用 `TryFrom`/`TryInto` 或 `parse`。
- `as` 可能截断，使用前确认范围。
- 用 `checked_*`、`saturating_*`、`wrapping_*` 明确整数溢出策略。

## 验收

- 能区分不可变、`mut`、shadowing 和 `const`。
- 能解释 `String`/`&str`、`Vec`/slice、move/Copy/clone。
- 能用业务类型、`Option` 和显式转换消除无效输入。
