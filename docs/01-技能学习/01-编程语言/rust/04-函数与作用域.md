# Rust：函数与作用域

Rust 函数签名不仅描述类型，还显示值是被读取、独占修改还是消费。

## 参数和返回值

```rust
fn inspect(config: &Config) {}
fn update(config: &mut Config) {}
fn consume(config: Config) {}
fn create(config: Config) -> Result<Service, Error> {}
```

- `&T` 是共享借用，可同时有多个。
- `&mut T` 是独占可变借用，有效期间不能存在其他访问。
- `T` 按值传入，非 `Copy` 值通常转移所有权。
- 返回拥有型值通常比返回内部引用更容易维护。

最后一个无分号表达式是返回值；`return` 更适合提前退出。

## 作用域与生命周期关系

值通常在所有者离开作用域时执行 `Drop`。借用可以在最后一次使用后提前结束，但绝不能超过被借用值的实际寿命。生命周期标注描述引用之间的关系，不会延长任何对象寿命。

```rust
fn first<'a>(left: &'a str, _right: &str) -> &'a str {
    left
}
```

只有返回引用、结构体保存引用或关系无法推断时才显式标注。业务对象通常优先拥有数据，避免生命周期参数向系统各层传播。

## 闭包

- `Fn`：可通过共享引用重复调用。
- `FnMut`：会修改捕获状态。
- `FnOnce`：可能消费捕获值，至少只能保证调用一次。
- `move` 让闭包取得捕获值所有权，但不会自动深复制。

异步任务和线程闭包通常需要拥有数据；同时要避免为了满足 `'static` 到处使用 `Arc`。

## 验收

- 能从签名判断共享借用、独占借用和所有权转移。
- 能解释词法作用域、实际借用范围和生命周期标注。
- 能根据回调是否修改或消费状态选择闭包 trait。
