# Rust：自定义类型与抽象

Rust 没有传统 class 和类继承。它用 `struct`/`enum` 表达数据，用 `impl` 封装行为，用 trait 和组合实现多态与复用。

## struct、enum 与 impl

```rust
pub struct Task {
    id: TaskId,
    state: State,
}

pub enum State {
    Pending,
    Running { started_at: Instant },
    Failed(String),
}

impl Task {
    pub fn start(&mut self) -> Result<(), StateError> { /* ... */ }
}
```

字段默认私有，模块边界和公开方法形成封装；`struct` 表达数据同时存在，`enum` 表达多个状态只存在一个。构造函数是普通关联函数，通常命名为 `new`、`try_new` 或具体业务动作。

## trait 与多态

```rust
trait Storage {
    fn get(&self, id: TaskId) -> Result<Option<Task>, Error>;
}

fn load<S: Storage>(storage: &S, id: TaskId) -> Result<Task, Error> {
    storage.get(id)?.ok_or(Error::NotFound)
}
```

- 泛型加 trait bound 通常单态化，实现编译期多态。
- `dyn Trait` 是 trait object，通过虚表实现运行时多态。
- 默认方法和组合可复用行为，不需要继承字段和实现。
- 关联类型表达 trait 与某个输出类型之间的固定关系。
- orphan rule 禁止“外部 trait + 外部类型”的实现；newtype 可建立本地扩展边界。

## 为什么不提供类继承

继承同时耦合数据布局、实现复用和子类型关系，容易形成脆弱基类和深层层级。Rust 将这三件事拆开：字段复用靠组合，行为契约靠 trait，运行时替换靠 `dyn Trait`。封装、抽象和多态都存在，只是不绑定到 class 语法。

## 验收

- 能用私有字段和 `impl` 维护对象不变量。
- 能使用 enum 消除非法状态，用组合替代实现继承。
- 能解释泛型静态分派与 `dyn Trait` 动态分派的成本和边界。
