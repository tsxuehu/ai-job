# Rust

Rust 的核心是把所有权、可变性、线程安全和错误处理写进类型与函数签名。快速学习时不要急着“战胜借用检查器”，先画清谁拥有数据、谁临时借用、借用需要持续多久。

> 开始真实项目之前，先阅读 [Rust 项目特性与注意事项](项目注意事项.md)；建立完整 workspace 时使用 [Rust 企业级项目结构](企业级项目结构.md)。

## 七天快速上手

1. 第 1 天：完成变量、类型、模式匹配、`String`/`&str` 练习。
2. 第 2 天：使用 struct、enum、`Vec`、`HashMap` 和迭代器建模。
3. 第 3 天：集中训练移动、借用、生命周期和 `Result`。
4. 第 4 天：建立多模块 Cargo 项目，完成文件 IO 和序列化。
5. 第 5 天：使用 trait、泛型和 trait object 实现可替换存储。
6. 第 6 天：实现线程任务队列和异步 API，验证取消与阻塞隔离。
7. 第 7 天：运行测试、Clippy、格式化和 profiler，整理安全边界。

七天目标是建立正确心智模型，而不是记住全部标准库或生命周期语法。

## 需要学习

- 所有权、移动、借用、生命周期和模式匹配。
- `Option`、`Result`、错误传播、trait、泛型和 trait object。
- `Send`/`Sync`、线程、`Arc`/`Mutex`。
- async/await、Tokio 和阻塞任务隔离。
- Cargo、feature、测试、unsafe 边界和 FFI。

## 验收

实现一个异步网络服务或高性能组件；能够解释所有权如何保证内存与线程安全，并清楚标注和验证 unsafe 边界。

建议验收项目：实现一个异步任务 API，包含输入校验、持久化接口、并发限制、超时、取消、优雅停机、日志指标和测试。阻塞操作必须与异步执行线程隔离。
