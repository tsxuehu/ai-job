# Rust：并发与异步

Rust 在编译期阻止许多内存级竞争，但事务一致性、锁顺序、背压和任务生命周期仍由开发者设计。

## Send、Sync 与线程

- `Send`：值可安全转移到其他线程。
- `Sync`：`&T` 可安全在线程间共享。
- 编译器根据字段自动推导大多数类型是否满足它们。

```rust
let shared = Arc::new(Mutex::new(State::default()));
let worker_state = Arc::clone(&shared);
let handle = std::thread::spawn(move || {
    worker_state.lock().unwrap().process_one();
});
handle.join().expect("worker panicked");
```

channel 适合传递消息和所有权，锁适合保护小型共享不变量。不要在锁内执行阻塞 IO、用户回调或长计算。

## Future 与 async/await

`async fn` 返回 Future；Future 被执行器轮询才推进。语言只定义状态机和轮询协议，计时器、网络 IO、任务调度由 Tokio 等运行时提供。

```rust
async fn fetch(client: &Client) -> Result<Data, Error> {
    Ok(tokio::time::timeout(TIMEOUT, client.get()).await??)
}
```

- async 适合大量等待 IO，不会自动加速 CPU 计算。
- 阻塞调用移到专用阻塞池，不能占住执行器线程。
- 丢弃 Future 通常表示取消，但底层副作用是否停止取决于实现。
- 避免跨 `.await` 持有同步锁；任务结果必须被观察。

## 背压与生命周期

使用有界 channel、semaphore 和总任务预算限制在途工作。优雅停机需要停止接收、发出取消、等待有限时间、处理未完成副作用。每个 spawn 都要有拥有者、等待或取消策略。

- 能实现带容量、超时、取消、错误传播和优雅停机的任务服务。
