# Rust：基础语法

Rust 的语法服务于一个核心目标：让类型、所有权、失败和并发约束尽量在编译期显式化。

## 最小程序

```rust
fn main() {
    let port: u16 = 8080;
    println!("listen on {port}");
}
```

- 语句通常以分号结束；不带分号的块尾表达式可以产生值。
- `fn` 定义函数，`let` 创建绑定，`::` 访问类型或模块中的项目。
- `println!` 名称末尾的 `!` 表示它是宏，不是普通函数。
- `//`、`/* */` 是注释，`///` 和 `//!` 是可生成文档的注释。

## 表达式语言

```rust
let level = {
    let score = calculate();
    if score >= 90 { "high" } else { "normal" }
};
```

代码块、`if` 和 `match` 都可以返回值。末尾多写一个分号会把表达式结果变成 `()`，这是新手最常见的类型错误之一。

## 名称与可见性

- 项默认私有，使用 `pub`、`pub(crate)` 精确开放边界。
- 标识符通常使用 `snake_case`，类型和 trait 使用 `UpperCamelCase`，常量使用 `UPPER_SNAKE_CASE`。
- 属性写作 `#[...]`，用于条件编译、lint、派生实现和测试标记。
- 宏适合生成重复语法或实现普通函数做不到的编译期能力，不应掩盖普通业务流程。

## 工具基线

使用稳定版工具链，从一开始运行 `cargo fmt`、`cargo check` 和 `cargo clippy`。读懂编译器诊断中的“值在哪里移动、借用持续到哪里、需要什么 trait”比背错误编号重要。

## 验收

- 能解释语句、表达式、块尾值和 `()`。
- 能区分函数、宏、属性和模块路径。
- 能创建最小 Cargo 程序并根据诊断修复基础编译错误。
