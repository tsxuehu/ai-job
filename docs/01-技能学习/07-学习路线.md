# 学习路线与验收标准

## 1. 能力自评

为每项技能标记等级：

- 0：不了解。
- 1：理解概念，但不能独立实现。
- 2：能独立实现，缺少生产经验。
- 3：有生产实践，能排障和优化。
- 4：能设计复杂方案并指导他人。

优先学习目标 JD 高频、且自己处于 0—1 级的 P0 能力。

## 2. 十二周参考路线

| 周次 | 学习内容 | 验收产出 |
| --- | --- | --- |
| 1—2 | 主语言、数据结构与算法 | 完成一个命令行/小型服务；20 道代表题 |
| 3 | 操作系统、网络 | 画出请求链路；完成 CPU/内存/网络排障实验 |
| 4 | SQL、索引、事务 | 设计表结构；分析执行计划和慢 SQL |
| 5 | Redis、消息队列 | 实现缓存与幂等消费；模拟异常恢复 |
| 6 | API、安全、测试 | 完成鉴权、参数校验、测试和安全检查 |
| 7 | 分布式与系统设计 | 完成两个系统设计和容量估算 |
| 8 | Docker、CI/CD、观测 | 容器化部署；接入日志、指标、追踪 |
| 9 | 模型 API 与结构化输出 | 完成流式对话、超时、重试、成本记录 |
| 10 | RAG | 完成混合检索、引用、权限和检索评测 |
| 11 | Agent 与工具调用 | 完成工具权限、状态、失败恢复和审计 |
| 12 | 综合项目 | 压测、回归评测、架构说明和项目复盘 |

已有后端经验时，可以跳过已达到 3 级的模块，把时间放在 AI 应用和薄弱项。

## 3. 真正掌握的判断标准

对每个技能都问自己：

- 能否不用搜索，用自己的话解释？
- 能否从零实现一个最小版本？
- 能否写测试证明正确？
- 能否说出失败场景、限制和替代方案？
- 能否用工具定位问题并给出数据证据？
- 能否在真实项目中说明它产生的结果？

只看完课程、复制 demo 或让 AI 生成代码，不算掌握。
