# 学习路线与验收标准

## 1. 能力自评

为每项技能标记等级：

- 0：不了解。
- 1：理解概念，但不能独立实现。
- 2：能独立实现，缺少生产经验。
- 3：有生产实践，能排障和优化。
- 4：能设计复杂方案并指导他人。

优先学习目标 JD 高频、且自己处于 L0—L1 的必修能力。

## 2. 十二周求职就绪冲刺

这是一条高强度参考路线，不代表十二周可以成为技术专家。目标是完成 L0—L2 的关键证据；基础薄弱时应延长周期，已有经验时可以按验收结果跳过内容。

| 周次 | 学习内容 | 验收产出 |
| --- | --- | --- |
| 1—2 | 主语言、数据结构与算法 | 小型服务；20 道代表题；测试与调试记录 |
| 3 | 操作系统、网络 | 请求链路图；CPU/内存/网络实验报告 |
| 4 | SQL、索引、事务 | P0 数据模型、迁移、执行计划和慢 SQL 分析 |
| 5 | API、安全、测试 | P0 鉴权、权限、参数校验和自动化测试 |
| 6 | 容器、文档与交付 | P0 一条命令启动、OpenAPI、演示与复盘 |
| 7 | Redis、消息队列 | P1 缓存和幂等消费；一致性实验 |
| 8 | 分布式与系统设计 | P1 容量估算、状态机和两个 ADR |
| 9 | CI/CD、观测与排障 | 日志、指标、Trace、发布和回滚演练 |
| 10 | 压测与故障恢复 | P1 压测报告、三类故障注入和事故复盘 |
| 11 | 岗位专项 | 普通后端强化主栈；AI 岗位完成模型 API 与 RAG 基线 |
| 12 | 项目与面试闭环 | 项目材料、完整模拟面试、差距复盘和下一阶段计划 |

AI 岗位需要在此基础上继续完成 P2，不能用模型接口替代 P0、P1 的工程训练。已有后端经验时，可以跳过已有可靠证据的模块，把时间放在 AI 应用和薄弱项。

## 3. 真正掌握的判断标准

对每个技能都问自己：

- 能否不用搜索，用自己的话解释？
- 能否从零实现一个最小版本？
- 能否写测试证明正确？
- 能否说出失败场景、限制和替代方案？
- 能否用工具定位问题并给出数据证据？
- 能否在真实项目中说明它产生的结果？

只看完课程、复制 demo 或让 AI 生成代码，不算掌握。
