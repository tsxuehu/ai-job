# 故障排查与性能优化

## 结构化流程

1. 确认影响范围、症状、开始时间和严重度。
2. 止损：回滚、降级、隔离、限流或扩容。
3. 查看关键指标并对比发布、配置、流量和依赖变化。
4. 用日志、Trace、Profile 和最小实验验证假设。
5. 修复、回归、补监控，完成复盘和防复发措施。

## 高频场景

- CPU 100%、内存增长、Full GC、死锁和协程泄漏。
- 数据库连接池耗尽、慢 SQL、锁等待和复制延迟。
- Redis 延迟、缓存命中下降、Kafka 消费积压。
- P99 突增、下游变慢、网络抖动和重试雪崩。
- 单一租户或热点 Key 拖垮系统。
- 发布后错误率上升或 AI 模型质量突然回退。

面试官重点观察你是否先收集证据、控制影响，再逐步缩小范围，而不是一开始猜根因。
