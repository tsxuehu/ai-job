# 系统设计

## 回答顺序

1. 澄清用户、功能、边界和成功指标。
2. 确定 QPS、数据量、读写比、延迟、一致性和可用性。
3. 定义核心 API 与数据模型。
4. 给出最小可行架构并走通主链路。
5. 估算计算、带宽和存储，识别瓶颈。
6. 深挖缓存、消息、分片、一致性和并发控制。
7. 补充限流、容灾、观测、安全、成本与演进。

## 练习题

- 短链接、秒杀、订单支付、通知、聊天和 Feed。
- 文件上传、搜索、日志、配置中心和任务调度。
- 多租户 SaaS、API/模型网关、企业知识库和客服 Agent。

## 评分重点

会不会先问需求、估算规模、识别瓶颈和关键一致性；能否处理重复、乱序、超时、部分失败，并清楚说明方案代价。
