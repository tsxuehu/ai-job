# 编码与算法

## 考察内容

- 数组、字符串、哈希、链表、栈、队列、树、堆和图。
- 二分、滑动窗口、双指针、BFS/DFS、回溯、贪心和动态规划。
- 时间/空间复杂度、正确性、边界、异常和测试。
- 代码命名、拆分、可读性和沟通过程。

## 回答流程

1. 复述问题，确认输入、输出、规模和异常。
2. 用例子验证理解，先给可行方案。
3. 选择数据结构，说明复杂度和正确性。
4. 编写完整代码，主动测试正常与边界场景。
5. 发现瓶颈后再优化，并说明代价。

## 准备标准

使用主语言完成 60—100 道有代表性的题。每道题都能讲思路、复杂度、边界和替代方案；同时练习无 IDE、允许 AI 和禁止 AI 三种环境。
