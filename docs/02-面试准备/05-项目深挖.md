# 项目深挖

## 每个项目必须准备

- 背景：用户和业务问题是什么？
- 目标：成功指标和非功能要求是什么？
- 规模：QPS、数据量、峰值、延迟和可用性。
- 约束：时间、预算、合规和团队资源。
- 方案：比较过什么，为什么这样选择？
- 实现：数据流、数据模型、一致性和失败处理。
- 上线：测试、灰度、迁移、观测和回滚。
- 结果：指标前后变化和业务收益。
- 贡献：自己具体负责什么。
- 复盘：故障、错误决策以及重做时的改变。

## 表达标准

不要只说“使用 Redis、Kafka、Kubernetes”。使用“问题 + 约束 + 选择依据 + 关键实现 + 量化结果 + 复盘”的结构；所有数字必须能解释测量口径。

AI 项目还要准备文档规模、检索与权限方案、评测集、质量、P95/P99、单次成本、安全措施和模型升级回归结果。
