# 操作系统与网络面试

## 高频问题

- 进程、线程、协程有什么区别？上下文切换代价是什么？
- 虚拟内存、Page Cache、文件描述符和 IO 多路复用怎样工作？
- 死锁的条件是什么，如何发现和避免？
- TCP 如何建立/关闭连接并保证可靠性？
- HTTP/1.1、HTTP/2、HTTP/3 与 TLS 有什么差异？
- DNS、代理、负载均衡和连接池位于请求链路的哪里？
- WebSocket、SSE 和轮询怎样选择？
- 超时、重试和退避应如何设置，为什么会形成重试风暴？

## 回答要求

不要只背定义。需要联系线程阻塞、连接耗尽、流式响应、网络抖动等真实故障说明观察方法与处理步骤。
