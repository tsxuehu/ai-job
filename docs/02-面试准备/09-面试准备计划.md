# 面试准备计划

开始前先建立 [能力映射](00-能力映射.md)，每次完整模拟使用 [模拟面试评分表](10-模拟面试评分表.md)。低分项必须回到学习、实验或项目补证据，不能只修改口头答案。

## 1. 六周参考计划

| 周次 | 准备内容 | 验收方式 |
| --- | --- | --- |
| 1 | JD 分析、简历、主语言 | 差距表；60 秒自我介绍；主语言模拟 |
| 2 | 算法、操作系统、网络 | 限时编码；基础知识模拟 |
| 3 | 数据库、Redis、消息队列 | SQL 实操；中间件场景问答 |
| 4 | 分布式、系统设计、排障 | 3 次 45 分钟系统设计 |
| 5 | AI 应用专项 | RAG/Agent 设计；评测、安全和成本问答 |
| 6 | 项目、行为、全流程模拟 | 3 场模拟面试并逐题复盘 |

目标是普通后端岗位时，第 5 周可改为主语言框架、性能调优或业务领域专项。

## 2. JD 对齐表

收集 10—20 个目标职位，把要求归类：

- 主语言与框架。
- 数据库、缓存和消息队列。
- 分布式、云原生和生产工程。
- AI、RAG、Agent 和模型服务。
- 行业知识。
- 职级和协作要求。

优先准备出现频率高且自己没有证据的能力，不要用完全相同的准备内容投所有岗位。

## 3. 面试前检查表

### 能力与材料

- [ ] 能用主语言完成限时编码和测试。
- [ ] 能回答主语言运行时、并发、内存和框架问题。
- [ ] 数据库、缓存、消息、网络、分布式没有明显盲区。
- [ ] 至少完成三次系统设计模拟。
- [ ] 两个项目可以讲清背景、规模、方案、结果和复盘。
- [ ] 准备六个行为故事。
- [ ] AI 岗位已准备 RAG、Agent、评测、安全和成本。
- [ ] 简历中的每个技术和数字都能经受追问。

### 面试当天

- [ ] 打开简历和 JD，准备纸笔和备用网络。
- [ ] 确认是否允许 AI、IDE、联网和代码模板。
- [ ] 编码前先确认输入、输出、规模和异常。
- [ ] 系统设计先明确需求和量级，再给架构。
- [ ] 项目回答突出个人行动、依据和量化结果。
- [ ] 不懂时说明知识边界和验证方法，不编造答案。

## 4. 每场面试复盘

记录：

- 面试题和追问。
- 自己的回答及卡点。
- 正确思路和遗漏内容。
- 问题属于知识、编码、表达、项目证据还是时间管理。
- 下一次面试前要完成的具体动作。

复盘的目标不是收集更多题，而是消除重复出现的失败原因。

## 5. 反问面试官

- 团队当前最重要的业务和工程问题是什么？
- 这个岗位入职 3—6 个月怎样算成功？
- 团队如何做设计评审、发布和事故复盘？
- AI 功能使用哪些离线、线上和业务指标？
- 如何平衡模型质量、数据安全、延迟和成本？
