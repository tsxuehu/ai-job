# AI 系统设计

## 常见题目

- 带权限和引用的企业知识助手。
- 智能客服与人工转接。
- 自动退款或工单处理 Agent。
- 自然语言数据分析系统。
- 代码审查助手和多模型网关。
- 可恢复的长任务 Agent 平台。

## 必须覆盖

- 数据来源、同步、权限和隐私。
- Prompt/RAG/微调选择及质量评测。
- 工具权限、幂等、审批、沙箱和审计。
- 状态、任务恢复、超时、限流、熔断和降级。
- 模型/提示/知识库版本及灰度回滚。
- 首 token 延迟、总延迟、token、成本和任务成功率。

AI 设计题首先是系统设计题，其次才是模型与 Prompt 题。
