# 二、面试考察内容

面试准备的目标不是背出更多答案，而是把学习和项目能力转化为准确、结构化、可验证的表达。先阅读 [能力映射](00-能力映射.md)，再根据目标 JD 选择下面的专项内容。

## 使用流程

1. 收集目标 JD，确定面试环节和高频能力。
2. 为每个简历技术点建立问题、代码、指标和故障证据。
3. 按专项完成限时练习，不看答案进行首次作答。
4. 使用 [模拟面试评分表](10-模拟面试评分表.md) 完整模拟。
5. 把失分归类为知识、实践、证据、表达或时间管理问题。
6. 回到学习、实验或项目补齐证据，再用同类问题复测。

## 常见面试环节

| 环节 | 主要考察 |
| --- | --- |
| 简历筛选/HR | 经历匹配、求职动机、沟通和稳定性 |
| 编码 | 数据结构、算法、代码质量、测试和表达 |
| 语言专项 | 主语言运行时、并发、内存、框架和排障 |
| 后端基础 | 网络、操作系统、数据库、缓存、消息和分布式 |
| 项目深挖 | 项目真实性、个人贡献、指标、取舍和复盘 |
| 系统设计 | 需求澄清、架构、容量、一致性、可靠性和成本 |
| AI 专项 | 模型接入、RAG、Agent、评测、安全和成本 |
| 行为面试 | Ownership、协作、冲突处理、影响力和成长性 |

不含 AI 的普通后端岗位仍然以主语言、计算机基础、项目和系统设计为核心。AI 相关岗位是在后端基本功之上增加专项考察。

## 应届生的证据标准

应届生可以主要使用课程实验、个人项目、比赛、开源和实习证据，但必须如实说明规模和个人贡献。不需要伪装生产经验，也不要在没有测量环境时写夸大的 QPS、用户数和业务收益。

一个可信回答通常包含：结论、原理、适用场景、失败模式、技术取舍和自己的项目证据。
