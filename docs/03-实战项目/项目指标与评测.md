# 项目指标与评测

## 后端指标

- QPS、并发数、成功率和错误分类。
- P50/P95/P99 延迟、首 token 延迟。
- CPU、内存、GC/事件循环/协程、连接池。
- 缓存命中率、队列积压和任务成功率。
- 可用性、恢复时间、发布回滚耗时。

## AI 质量指标

- 检索 Recall@K、MRR、nDCG。
- 回答正确性、完整性、引用准确率。
- 无答案时的拒答准确率。
- 工具选择、参数和端到端任务成功率。
- 提示注入、越权访问和危险工具测试通过率。

## 成本指标

- 单次请求输入/输出 token 和模型成本。
- 单次成功任务成本，而非只看单次模型调用。
- 缓存节省、不同模型路由比例和失败重试成本。

## 评测报告模板

1. 数据集来源、规模、场景分布和版本。
2. 当前基线、目标和上线门槛。
3. 本次变更及唯一主要变量。
4. 总体与分组指标、失败样本和安全结果。
5. 延迟、成本和质量之间的取舍。
6. 是否上线、灰度比例、监控与回滚条件。
