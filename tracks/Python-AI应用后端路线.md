# Python AI 应用后端路线

## 目标

使用 Python 完成可靠的 API 和 AI 应用服务，理解解释器、异步 IO、类型、测试、性能边界以及模型调用治理。

## 阶段安排

### L0：语言与工具

- 数据模型、迭代器、生成器、上下文管理器、异常和类型标注。
- 虚拟环境、依赖锁定、格式化、静态检查和测试。
- 使用调试器、日志和分析工具完成小型程序。

### L1：服务开发

- Web 框架、请求校验、依赖管理、中间件和错误处理。
- SQL、连接池、事务、迁移和集成测试。
- asyncio、任务取消、超时、线程池和进程池的边界。
- 完成 P0 的 API、鉴权、数据访问和测试。

### L2：AI 应用与生产

- 模型 API、流式输出、结构化输出、工具调用和多模型适配。
- RAG 的数据处理、权限检索、引用和评测。
- Agent 的状态、幂等、审批、审计和失败恢复。
- 使用指标和分析工具定位事件循环阻塞、内存及依赖延迟。
- 完成 P1 的生产工程验收和 P2 的核心 AI 闭环。

## 必须理解的边界

- 异步函数不能自动解决 CPU 密集任务和阻塞依赖问题。
- 类型标注和数据校验不能替代运行时测试。
- 快速拼接模型调用不能替代权限、评测、安全和成本治理。
- 性能不足时应先测量瓶颈，再选择并发、缓存、批处理、进程或其他语言服务。

## 验收证据

- 一个可以一条命令启动、依赖可复现的 Python API 服务。
- 单元测试、集成测试、类型检查、迁移和 OpenAPI 文档。
- 一份事件循环阻塞或内存问题分析报告。
- 一份 RAG 或 Agent 的质量、延迟、安全和成本评测报告。
- 能回答 [Python 面试](../docs/02-面试准备/02-编程语言面试/Python面试.md) 中的问题并接受追问。
