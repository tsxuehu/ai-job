# Go 后端路线

## 目标

使用 Go 完成 P0 和 P1，能够解释 goroutine、channel、调度、内存、网络服务和常见并发故障。

## 阶段安排

### L0：语言与工具

- 类型、接口、错误处理、包管理、测试和标准库。
- slice、map、指针、defer、资源释放和代码组织。
- 使用格式化、静态检查、竞态检测和基准测试工具。

### L1：服务开发

- HTTP 服务、Context、参数校验、中间件和优雅停机。
- 数据库访问、连接池、事务、迁移和集成测试。
- goroutine、channel、select、同步原语和取消传播。
- 完成 P0 的 API、鉴权、数据访问和测试。

### L2：生产与分布式

- 调度模型、逃逸分析、GC、内存分配和并发模式。
- 超时、重试、限流、熔断、背压和资源隔离。
- 使用 pprof、trace、指标和竞态检测定位问题。
- 完成 P1 的缓存、消息、可观测性、压测和故障演练。

### AI 应用扩展

- 实现模型流式输出、结构化结果校验和取消传播。
- 对外部模型调用建立并发限制、超时、降级和成本指标。
- Python 可以承担离线数据处理和评测。

## 验收证据

- 一个可以一条命令启动的 Go 服务。
- 单元测试、集成测试、数据库迁移和 OpenAPI 文档。
- 一份竞态、goroutine 泄漏或内存问题分析报告。
- 一次包含基准数据和 pprof 证据的性能优化。
- 能回答 [Go 面试](../docs/02-面试准备/02-编程语言面试/Go面试.md) 中的问题并接受追问。
