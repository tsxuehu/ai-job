# 技术栈路线

技术栈路线用于把通用能力映射到具体语言生态。仓库不要求学习所有语言；选择一条主路线完成项目和面试，其他语言只在有明确用途时学习。

## 路线

- [Java 后端路线](Java后端路线.md)：适合希望深入 JVM、Spring 生态和复杂业务系统的人。
- [Go 后端路线](Go后端路线.md)：适合希望深入并发、网络服务、云原生和平台工程的人。
- [Python AI 应用后端路线](Python-AI应用后端路线.md)：适合偏向 AI 集成、数据处理和快速服务开发的人。

Node.js 和 C++ 的知识入口保留在 [编程语言目录](../docs/01-技能学习/01-编程语言/README.md)。当目标 JD 明确需要时，可以按照 [学习章节模板](../templates/学习章节模板.md) 补充完整路线。

## 共同要求

无论选择哪条路线，都不能跳过：

- 数据结构与算法、操作系统、网络和 Linux。
- SQL、事务、索引、Redis、消息队列和分布式基础。
- API、安全、测试、容器、发布和可观测性。
- 至少完成 P0、P1 两个阶段的核心验收。
- 使用语言对应的性能与故障分析工具完成一次实验。

框架 API 会变化，运行时、并发、数据一致性和生产工程能力更值得长期投入。
