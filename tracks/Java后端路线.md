# Java 后端路线

## 目标

使用 Java 完成 P0 和 P1，能够解释 JVM、并发、Spring 请求链路、数据库事务和常见生产故障。

## 阶段安排

### L0：语言与工具

- Java 语法、集合、泛型、异常、IO、测试和构建工具。
- 面向对象设计、不可变对象、资源释放和错误边界。
- 使用调试器、日志和 Git 完成小型程序。

### L1：服务开发

- JVM 内存、类加载、垃圾回收和线程模型。
- Spring Boot、依赖注入、Web 请求链路、配置和测试。
- JDBC、连接池、ORM、事务传播和数据库迁移。
- 完成 P0 的 API、鉴权、数据访问和测试。

### L2：生产与分布式

- Java Memory Model、锁、CAS、线程池和并发容器。
- 超时、重试、隔离、限流、熔断和优雅停机。
- JVM 指标、线程转储、堆转储、GC 日志和性能分析。
- 完成 P1 的缓存、消息、可观测性、压测和故障演练。

### AI 应用扩展

- 以 HTTP/SDK 接入模型 API，处理流式响应和结构化输出。
- 对模型调用配置独立线程池、超时、限流、熔断与成本记录。
- Python 可以承担离线评测、数据清洗和实验脚本。

## 验收证据

- 一个可以一条命令启动的 Spring Boot 项目。
- 单元测试、集成测试、数据库迁移和 OpenAPI 文档。
- 一份线程或 GC 问题分析报告。
- 一次有环境、数据和前后对比的性能优化。
- 能回答 [Java 面试](../docs/02-面试准备/02-编程语言面试/Java面试.md) 中的问题并接受追问。
